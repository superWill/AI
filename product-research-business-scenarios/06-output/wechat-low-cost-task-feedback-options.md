# 普通微信群任务领取与进度反馈：最省钱方案表

## 结论

最省钱、最稳的方案不是机器人，而是：

`普通微信群 + 腾讯文档收集表 / 腾讯问卷`

微信群只负责：
- 发任务
- 发提醒
- 发链接

结构化数据放在表单里收，不依赖机器人去理解群聊天。

## 方案对比表

| 方案 | 怎么做 | 初始成本 | 月成本 | 自动化程度 | 稳定性 | 是否推荐 |
| --- | --- | --- | --- | --- | --- | --- |
| 微信群 + 腾讯文档收集表 | 群里发任务，成员点收集表领取和反馈，后台看汇总表 | 0 | 0 起 | 低 | 高 | 最推荐 |
| 微信群 + 腾讯问卷 | 群里发任务，成员点问卷领取和反馈，结果自动统计 | 低 | 约 208 元/月起 | 低到中 | 高 | 推荐 |
| 微信群 + 人工群接龙 | 群里直接接龙，管理员人工整理 Excel | 0 | 0 | 很低 | 中 | 仅适合极小规模 |
| 微信群 + 安卓托管机器人 | 用手机监听消息、自动识别、自动回写 | 中 | 不固定 | 中到高 | 低 | 不推荐做正式方案 |

## 推荐落地表

| 模块 | 最省钱做法 | 说明 |
| --- | --- | --- |
| 任务派发 | 微信群发消息 | 每条任务必须带任务 ID |
| 领取任务 | 一个“领取任务”收集表 | 填任务 ID、领取人、预计到场时间 |
| 反馈进度 | 一个“进度反馈”收集表 | 填任务 ID、状态、说明、图片 |
| 数据汇总 | 腾讯文档在线表格 | 按任务 ID 汇总 |
| 报表导出 | 腾讯文档导出 Excel | 每日或每周导出 |
| 催办 | 群里人工提醒 | 第一版先不用自动催办 |

## 建议字段

### 领取任务表

| 字段 | 是否必填 |
| --- | --- |
| 任务 ID | 是 |
| 领取人 | 是 |
| 手机号 | 否 |
| 预计到场时间 | 否 |
| 备注 | 否 |

### 进度反馈表

| 字段 | 是否必填 |
| --- | --- |
| 任务 ID | 是 |
| 当前状态 | 是 |
| 处理说明 | 是 |
| 图片/文件 | 否 |
| 反馈时间 | 是 |
| 反馈人 | 是 |

建议 `当前状态` 固定成：
- 已领取
- 已到场
- 处理中
- 已完成
- 异常

## 成本估算

| 方案 | 官方公开价格口径 | 适合阶段 |
| --- | --- | --- |
| 腾讯文档收集表 | 0 元起 | MVP、试点、小团队 |
| 腾讯问卷高级版 | 2499 元/年起 | 想要更规范统计但仍控成本 |
| 腾讯文档企业版基础版 | 250 元/用户/年 | 需要组织管理、权限、安全 |

按月粗算：
- 腾讯文档收集表：`0 元/月起`
- 腾讯问卷高级版：`约 208 元/月起`
- 腾讯文档企业版基础版：`约 20 元/人/月`

## 不推荐直接上机器人的原因

| 问题 | 说明 |
| --- | --- |
| 普通微信没有官方群机器人 | 我没有查到普通微信群官方开放 webhook / 回调能力 |
| 自由文本难结构化 | 群成员回复格式不一致，后期很难统计 |
| 托管机器人风险高 | 有封号、维护、稳定性风险 |
| 实际不省钱 | 研发和维护成本通常高于表单方案 |

## 最小执行模板

群里发：

```text
任务：T20260508-001
地点：XX 台区 A-01
要求：请负责人先领取，再处理完成后反馈进度
领取链接：xxx
反馈链接：xxx
```

## 最终建议

如果目标是`最省钱`，建议优先级如下：

1. 微信群 + 腾讯文档收集表
2. 微信群 + 腾讯问卷
3. 再考虑企业微信或飞书
4. 不要一开始就做普通微信机器人
