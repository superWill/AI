# Taiwan Semiconductor (TSM)

## ⭐ 2026-07-16:Q2'26 创纪录 + 好业绩救不了股价(估值绷紧) `[核实 2026-07-16]`

**Q2'26 实际(07-16 报)**:
- 营收 **NT$1.27万亿 / ~$39.6B**,创纪录,**YoY +36%**,超指引;**AI 芯片 ~61% 营收**。`[HIGH]`
- 毛利率 **~67%**(指引 65.5–67.5% 高端;JPM 估 69.5% = 分析师估计,非确认)。
- **2026 capex 确认 $52–56B、按高端花、+37% YoY、史上最大**——坐实 capex 在**加速**。`[MED-HIGH]`
- FY26 增速 **>30%(美元)**(Q1 电话会即给;**今日是否再上调未确认**,别当已上调)。
- **CoWoS**:售罄到 2026、交期 52–78 周、订单排到 2027;供需缺口 ~20%→年底 ~10%;月产能 ~130k(2026末)→170k(2027)。`[单一来源/行业追踪,非会上确认]`

**但股价在跌,创纪录业绩也没止血** `[方向 HIGH / 精确点位 MED]`:这窗口 TSM **−6~7%,并跌破 $420 支撑至 ~$401**(前瞻 P/E ~25x / PEG ~0.8)。原因:
1. **Sell-the-news + 估值绷紧**:年内 +52% 冲进财报,好业绩早 price 进;**P/E ~35x vs 五年中位 22.8x**。和两天前 ASML 一样(涨指引照跌)。
2. **海外厂(亚利桑那)+ N2 爬坡稀释毛利**——真实且持久的软点,连 Amkor 亚利桑那大单都没抵消。
3. **板块 risk-off**(AVGO 触发 SOXX 两日 −12.9%)裹挟。

**信号** `[INFERRED, MED-HIGH]`:**「强需求 ≠ 股票便宜」坐实**——ASML+TSM 两个全链最强最便宜的名字都在创纪录业绩下跌 = **约束是估值/仓位,不是 AI 需求**(good-news exhaustion)。**但不是顶部信号**:note 的真顶部信号是"CoWoS/capex 骤停",而此处 capex +37%、CoWoS 仍售罄 = **估值消化回撤,不是浪潮结束**。对组合:基本面确认**不构成追高理由**(好生意坏价格);下一读数 = 8 月 NVDA 增速二阶导 + 回撤企稳还是深化。见 [[2026-07-13-gui-internet-cycle-vs-ai-analog]]。

**合理估值(2026-07-16 复核)** `[INFERRED, MED]`:合理倍数 = **质量溢价 − 台海折价**,合理前瞻 P/E **~24–30x**。三档(FY26 EPS ~$15.8 = 估计):

| 情景 | 前瞻 P/E | 对应价 |
|---|---|---|
| 悲观(要大地缘折价+增长减速) | 20–22x | ~$315–350 |
| 基准(AI capex 续+正常折价) | 25–27x | ~$395–425 |
| 乐观(超级周期+折价收窄) | 29–32x | ~$460–505 |

**现价 ~$401 = 基准下沿(~25x),从"公允"滑向"公允偏便宜"**。要害:TSM 属 **AVGO 桶(好质量+公允价)非 PLTR 桶**——约束不是估值(PEG<1)是**台海尾部 + AI-capex 周期**;"合理估值"本质是**你要求多大台海折价**(巴菲特要 ~100%→清仓)。落刀未止(AVGO 信号+NVDA 8 月),便宜≠止跌。见 [[capital-preservation-first]]。

## 一句话定位

先进制程 + 先进封装**近独家**——每一颗领先 AI 芯片（含所有超大厂自研 ASIC）都在它这里流片。和 [ASML](ASML.md) 是制造链的孪生收税口："不管谁设计赢，都来我这印。"

## 护城河类型

**制造垄断 + 资本/工艺壁垒 + 客户信任**：

- 先进节点（3nm/2nm）领先且良率最高，客户无第二选择。
- CoWoS 等先进封装产能近独家，AI 芯片刚需。
- 资本开支 $500 亿+/年的壁垒，追赶者（Intel/三星）难复制。

## 短期增量（3–5 年）

- AI/HPC 需求驱动先进制程满载 + 持续涨价。
- 先进封装（CoWoS）扩产，瓶颈即定价权。
- 2nm 量产爬坡。

## 长期增量（10–20 年）

- 美国/日本建厂分散地缘风险，巩固全球代工地位。
- 每代节点都强化"无第二选择"格局。

## 风险

- **⚠️ 台海地缘（最大尾部风险）**：这是它与 ASML 的本质区别——ASML 是商业周期风险，TSM 是**地缘单点风险**。
- **资本开支强度**：$500 亿+/年，周期下行时折旧压力。
- **客户集中**：Apple / Nvidia 等大客户议价。

## 估值锚

- 类比：[ASML](ASML.md)（设备端孪生）；垄断却因地缘风险长期享"折价"。
- 当前估值相对增速/利润率合理（垄断折价），地缘是估值压制项。

## 退出条件

- 触发减仓：先进制程资本开支周期见顶、AI 需求降温。
- 触发卖出：台海地缘实质性升级。
- 再加码：地缘恐慌性下杀 + 先进封装供不应求延续。

## 跟踪信号

- 先进制程（3nm/2nm）占比与涨价
- **CoWoS 供需缺口 + 交期(本轮顶部领先指标)**:缺口从 ~20%→追是否逼近 0;交期从 52–78 周→追是否跌破 ~26 周;或 TSMC/Amkor 报 CoWoS **利用率下滑**——那是 note 的"暗光纤时刻"(约 2027)。共用于 [[NVDA]]/[[AMKR]]/[[MU]]
- 资本开支兑现（也是 ASML 订单的领先指标）
- 台海局势
