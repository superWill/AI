# Adobe (ADBE)

## 一句话定位

创意 + 文档软件霸主(Photoshop/Illustrator/Acrobat)。**2026 年被市场当"gen-AI 颠覆的首个大输家"——倍数从 5 年中位 >40x 砸到 ~11–13x,-31~37% YTD**。这是上一轮"现在还有 Apple 式便宜成长股吗"筛子里**唯一像样的候选**,但**它带的是真颠覆风险,不是 Apple-2016 那种纯错杀**。

## ⭐ 核心问题:Meta-2022 式错杀,还是价值陷阱?`[KNOWN 2026]`

> 和 Apple-2016 的本质区别:Apple 当年市场怕的"iPhone 见顶"是**纯粹搞错**(没真风险)→ 闭眼买。**Adobe 怕的"gen-AI 商品化创意软件"是真实、未解决的终局风险**——可能多头对(2-3x 重估),也可能空头对(价值陷阱)。**这是高赔率 + 真三振概率的一注,不是免费午餐。** 决定胜负的就两个数:**net-new ARR 拐不拐 + AI-First ARR 能不能 scale**。

## 多头论点(它是被错杀的)+ 证伪信号 `[KNOWN 2026]`

**论点(硬证据)**:
1. **AI 货币化是真的、在加速**:AI-First ARR >$5 亿(3×)、Firefly ARR ~$3 亿(+50% QoQ)、Acrobat AI 付费 MAU +150%、GenStudio +25%。**不是 PPT,是钱**。
2. **IP 赔付护城河(企业端杀手锏)**:Firefly **只用授权/公有领域数据训练** → 给付费用户**合同级 IP 侵权赔付**,Midjourney/DALL-E/Claude 给不了。**企业不敢用没赔付的生成工具** = gen-AI 对手抄不走的结构护城河。
3. **freemium pivot 是主动让利不是丢需求**:管理层故意**推迟 CC 涨价 + 把流量导向免费版**,短期牺牲 ARR 换 MAU 漏斗——**ARR 减速一半是自己按的,不是被打的**。
4. 记录营收 + 上调指引 + SEMrush 并入。

**🔴 多头证伪信号(出现=多头错,它是陷阱,撤)**:
1. **AI-First ARR / Firefly QoQ 增速 roll over**(货币化引擎 scale 不动)——**最关键的数**;
2. **过了"投资年",总 ARR 增速仍跌破 ~8% 且 net-new ARR 继续向下** → 证明是真丢需求,不是主动递延;
3. **Creative Cloud 净订阅数下滑 / 流失率飙**(不只是递延涨价)→ 护城河真在塌;
4. **企业端(赔付护城河所在)也减速** → 连最硬的腿都软,护城河论点死;
5. **毛利持续压缩**(freemium + AI 算力成本永久吃掉利润)。

## 空头论点(它是价值陷阱)+ 证伪信号 `[KNOWN 2026]`

**论点(硬证据)**:
1. **net-new ARR 连续 6 季下滑**,有机 ARR 10.5% 且还在掉——增长结构性减速;
2. **消费/prosumer 护城河在被侵蚀**:Canva($4B ARR、+35%)、Midjourney($5 亿营收)、Claude Design、免费开源工具抢价格敏感创作者;
3. **自己的 Firefly 在蚕食自己的 Adobe Stock 库存图业务**(管理层已亲口承认);
4. **17% CC 涨价已在边际加速流失**;
5. **🚨 治理真空**:CEO Shantanu Narayen(18 年)**3/12 宣布离职、无指定接班人**;**CFO 在 Q2 财报后几天内也走**——AI 转型中段领导层同时缺位,执行风险拉满。

**🟢 空头证伪信号(出现=空头错,它被错杀,fat pitch 坐实)**:
1. **net-new ARR 止跌回升**(减速停止/反转)——**单一最重要的反证**;
2. **AI-First ARR 复利到总 ARR 的实质占比**(如 >10–15%)→ 证明 Adobe 是 AI 货币化者而非被灭者;
3. **企业端靠赔付拿下大单**(GenStudio/Firefly 大企业合同)→ 护城河在要紧处守住;
4. **新 CEO 落定且有可信 AI/产品履历** → 拆掉执行真空 overhang;
5. **投资年后毛利企稳**。

## 入场纪律(按「重押原则」)`[INFERRED]`

- **别当 Apple-2016 闭眼买**:那笔没终局风险,这笔有。**按"可能错的概率注"定 size**——比无尾部风险的标的小,留三振空间。
- **决定变量明确 = 可等实锤再动**:未来 2-3 季的 **net-new ARR 拐点 + AI-First ARR 斜率**会先于股价告诉你是错杀还是陷阱。**不必猜,等这两个数转**——这正是"等证明再梭哈=买顶"的反面:这里证明成本低(就盯两个 ARR 数),且当前价已 priced-for-collapse,等到拐点确认时多半还没贵回去。
- **不赌唯一**:它是一注概率注,不是组合命运注。
