两家**事实垄断**精密减速器市场，门槛 = 30+ 年工艺积累 + 高精度齿轮加工设备 + 长寿命材料配方。

按 Tesla 目标 2027 量产 50,000 台计算，仅 Tesla 一家就需要 100–200 万个谐波减速器/年。
**当前 Harmonic 全球年产能仅 200–300 万个**。

## 护城河类型

**工艺壁垒 + 制造门槛**型护城河（最深的一种）：

- 谐波减速器 = 柔轮 + 刚轮 + 波发生器三件套
- 柔轮的弹性变形循环寿命要求 10^8 次以上 → 钢材热处理 + 精密加工工艺
- 30+ 年工艺积累 + 客户验证周期长（每个新设计要测试 1–2 年）
- 客户切换成本极高 → ABB / Fanuc / Yaskawa / KUKA / Universal Robots 30+ 年合作

## 风险

- **基本面风险**：
  - 制造业 capex 周期下行（2008/2019 都跌过 50%+）
  - 人形机器人量产推迟（Tesla Optimus 多次跳票）
- **估值风险**：
  - 历史 PE 30–80x，机器人 narrative 推升估值
  - 一年涨幅可能 100%+，回调风险高
- **政策/地缘风险**：
  - 日元贬值短期利好出口，但拉长看影响 EPS
  - 中国本土厂（绿的谐波、来福、汉宇科技）加速追赶 —— 中低端已被吃，高端仍领先 3–5 代
- **技术替代风险**：
  - 直驱电机（DDR）某些场景替代减速器 —— 但精度和成本不匹配人形机器人
  - **滚柱丝杠** 在直线传动场景替代谐波减速器（Tesla Optimus 选用滚柱丝杠路线）
    → 这是真正的风险：如果 Tesla 路线（滚柱丝杠）成为人形主流，谐波减速器需求减少 30–50%
    → 但 Figure / 1X / Boston Dynamics 仍用谐波减速器
    → **跟踪信号**：Tesla Optimus 量产规格 + 其他人形机器人厂的执行器选型
