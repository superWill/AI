# ASML Holding (ASML)

## 一句话定位

EUV 光刻**独家垄断**——7nm 以下先进芯片没有它一颗都造不出来。AI 硬件链里**最 provider-agnostic 的收税口**：不管 Nvidia / AMD / 谷歌 TPU / 博通 / 谁赢，都得买它的机器。"硅基消费"理论里最硬的一环。

## 关键数据（基准日 2026-06-19，网络调研）

| 指标 | 数据 |
|---|---|
| 市值 | **~$7000 亿**（欧洲最值钱上市公司） |
| Q1'26 净销售 | €88 亿（YoY +13%，环比降自 Q4'25 €97 亿，超预期） |
| 净利润 / EPS | €28 亿 / €7.15（基本） |

> 装机维护（installed base）€25 亿是**穿越周期的经常性收入**；EUV €41 亿是垄断定价核心。

## 护城河类型

**设备垄断 + 技术壁垒逐代加高**：

- EUV 光刻独家供应，High-NA EUV 是下一代独家。
- DUV 关键供应商。
- 进入壁垒以"十年 + 数千供应商生态"计，无可替代。

## 短期增量（3–5 年）

- AI 芯片需求驱动先进制程扩产 → EUV 系统出货。
- High-NA EUV 放量（单台 ~$4 亿）。
- 装机维护随装机量累积持续增长。

## 长期增量（10–20 年）

- 每代节点缩小都更依赖 ASML 独家光刻。
- 先进封装领域扩张（向 TSMC 腹地延伸）。

## 风险

- **采购周期波动**：设备订单 lumpy，Q1 环比已下滑；TSMC 在推迟 High-NA（嫌 $4 亿/台太贵），可能 2026–2029 少买 $50–100 亿设备。
- **⚠️ 对华出口管制**：先进光刻对华受限，政策悬剑（2026/6 仍有"先进机台是否流入中国"的争议）。
- **估值**：周期高位，需注意采购节奏拐点。

## 估值锚

- 类比：[TSM](TSM.md)（制造端孪生收税口）；垄断给溢价但受周期扰动。
- 关注 EUV 系统销售与 bookings 趋势，而非单季营收。

## 退出条件

- 触发减仓：先进制程资本开支周期见顶、bookings 连续下滑。
- 触发卖出：对华管制实质性永久收紧 + High-NA 推广受阻。
- 再加码：bookings 重新加速 + 周期回撤拉回估值。

## 跟踪信号

- EUV / High-NA 系统销售与 bookings
- 装机维护收入（穿越周期）
- TSMC / 三星 / Intel 资本开支（ASML 的订单来源）
- 对华出口管制政策（BIS / 荷兰政府）
