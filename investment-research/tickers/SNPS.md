# Synopsys (SNPS)

## 一句话定位

EDA 双寡头之一（与 [Cadence](CDNS.md) 合占 ~85%）。每一颗芯片——Nvidia、Broadcom、Marvell、超大厂自研 ASIC——都绕不开它的设计工具。2025/7 以 $350 亿收购 Ansys，从"设计芯片"扩到"多物理仿真 / 系统级设计"。是"不可或缺=订阅制收税"的极致形态。

## 护城河类型

**切换成本 + 双寡头 + 经常性收入**：

- 一个芯片家族绑定工具链后，迁移成本以"工程师-年/十年"计——"永不流失客户的双寡头"。
- 订阅制经常性收入，按晶圆/设计活动收税。
- Agentic AI（DSO.ai）把锁定从 UI 层深化到工具运行时和数据语义层。

## 短期增量（3–5 年）

- **AI 复杂度收税**：AI 芯片（先进节点、chiplet、定制 ASIC 潮）复杂度暴涨 → 单芯片消耗 EDA 工具量更大。
- **Ansys 协同**：多物理仿真 + 芯片设计交叉销售，TAM 外扩到系统级。
- **Agentic EDA 重定价**：DSO.ai 从"卖座位"转向"卖结果 / 按算力计费 / AI agent 按人头收费"。

## 长期增量（10–20 年）

- "从晶体管到整机"的全栈设计平台（芯片 + 多物理 + 系统仿真）。
- AI 到 2030 给 EDA 多带 ~$60 亿增量（Bloomberg）。

## 风险

- **⚠️ 中国出口管制（最大尾部风险）**：2025/5/23 BIS 禁令致其当场撤销指引，7/4 解禁——政策悬剑随时可重演，~16% 营收暴露。
- **整合风险**：Ansys $350 亿消化中，渠道/定价梳理未完。
- **基本面软点**：EDA 有机增速（+8%）低于 [CDNS](CDNS.md)，Design IP 走软。
- **估值风险**：TTM PE ~82x，安全垫薄。

## 估值锚

- 类比：[CDNS](CDNS.md)（更高质量、更贵）、Ansys 整合后的平台扩张故事。
- FY27 EPS $17.25 → 远期 PE ~27x，**若 Ansys 协同兑现其实不贵**——这是"反转 + TAM 扩张"赔率。
- 分析师目标 ~$560（+23%）。

## 退出条件

- 触发卖出：中国管制实质性永久收紧；Ansys 整合失败、协同不兑现。
- 触发减仓：EDA 有机增速持续低于 Cadence + 估值不消化。
- 再加码：中美摩擦恐慌性下杀拉回安全垫；Ansys 协同数据兑现。

## 跟踪信号

- **EDA 有机增速**（剔除 Ansys 并表）能否回升
- Ansys 协同 / 交叉销售兑现、Design IP 是否企稳
- 中国出口管制政策动向（BIS）
- DSO.ai 按结果/算力计费的收入占比
