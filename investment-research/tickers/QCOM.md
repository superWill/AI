边缘 AI 时代最容易被低估的“老平台公司”之一：本质不是单纯手机芯片商，而是`高端安卓 SoC + 基带/IP 授权 + 汽车 + IoT + PC + 数据中心定制硅`的组合体。

## 护城河类型

**标准必要专利 + 基带 / 连接技术 + 高端 SoC 集成能力 + 客户关系**

- `QTL` 许可业务仍是高利润护城河，本质是无线标准 IP 收费权
- `QCT` 在高端安卓手机 SoC 和基带上仍有系统级优势
- 从手机往外扩展时，QCOM 可以复用：
  - AI 推理
  - 低功耗计算
  - 连接
  - 车载平台
  - 边缘终端平台
- 汽车、XR、工业、PC 等业务不是从零开始，而是复用已有 IP 栈

### A. 核心结构性风险:核心从两端被侵蚀

| 风险 | 量级 | 性质 |
|---|---|---|
| **Apple 基带自研** | 失 ~$75亿/年(~18% 营收),**2027 归零**(份额今年 ~20%→0) | 已知、已量化的悬崖 |
| **🔴 China(比 Apple 大得多)** | **占营收 ~46% 且在升**(2023 37%→2024 46%) | **更大、更模糊、多向** |

**China 是更大的风险**(之前卡里严重低估):
- **国产替代**:小米 **XRING O1**(自研 3nm,投 ¥135亿,前高通高管带队,对标骁龙 8 Elite);**中国手机品牌自研芯片比例预计 30%(现)→60%(2026)**。这是 Apple 那套,但发生在 QCOM **最大市场、整个 OEM 基础**上。
- **降价压力**:XRING 量产逼 QCOM/联发科,**全球手机芯片价预计降 10-15%**。
- **+ 联发科竞争 + 地缘/出口管制尾部 + 当前中国手机周期疲软**。

### B. 但自研浪潮下,QCOM 的护城河在自研最做不动的地方

**用户洞察:"大厂都在自研,QCOM 优势在哪?" —— 答案是非对称的:**

1. **🥇 连接/基带护城河(最硬,自研复制不了)**:**Apple 买 Intel 基带、花 6+ 年、到 2025 才出 C1,而 C1 还不如 QCOM**。连 Apple(无限钱+最紧整合)都搞六年还更差 → 绝大多数公司做不动。蜂窝连接 = 几十年标准必要专利 + RF + 全球认证。**且 QTL royalty 不管用谁的芯片都收(中国用国产芯片照付)。**
2. **服务"养不起自研"的长尾**:Apple/小米能砸 $70亿;Oppo/Vivo/荣耀/摩托/三星中低端/几百中小厂养不起 → 需要 merchant。自研是巨头游戏,不是全行业。
3. **新市场(汽车/边缘/XR/IoT)= 客户没有芯片团队**:车厂/工业不自己造芯片 → 买 QCOM 平台。**QCOM 的增长区恰恰是自研管不到的地方。**

→ **QCOM 优势在转移:从"人人旗舰手机里的芯片"(被自研侵蚀)→ "自研复制不了的连接 IP + 自研管不到的新市场平台"。不是没护城河,是护城河在转移。**

### C. 资本保全契合度(2026-06-23)

- **符合**:便宜(21x,低于同业 42%)、产现金($200亿回购+股息)、out-of-favor(已跌 20%)、坏消息(Apple)已知已价、**几乎不沾 AI capex 见顶风险**(驱动是手机/汽车/边缘,非数据中心 capex)→ 对超配 AI-capex 的组合**反而有点分散性**。
- **但 China 抬高门槛**:核心被 Apple+China 两端侵蚀,**21x 是 cheap-for-a-reason(China 就是 reason)**;价值陷阱风险更高,+ 一条地缘永久损失尾部(脱钩升级=踩资本保全第④条)。
- **裁决**:它赌的是"连接护城河 + 汽车/边缘替换引擎 **>** Apple + China 双侵蚀"。最坏是**"价值陷阱/dead money 几年"而非永久损失**(连接干不掉、现金牛在、股息垫着)——这符合"宁愿错过不损失本金"。**值得当耐心价值仓,但前提是信替换引擎补得上 Apple+China 双洞、且地缘不升级——比单看 Apple 高的门槛。**

## ⭐ 2026-06-24 Investor Day：数据中心从"期权"变"签约豪赌"(两条腿)`[KNOWN 2026-06]`

> **本节取代下方"短期增量·#3 数据中心是最大新增期权"的旧口径(那段写于 Investor Day 前,已严重低估)。** 股票 Investor Day **盘后 +12-15%**(但身处弱芯片 tape);**Morningstar fair value $155→$200**。

**目标**:数据中心收入 **$0.3B(FY26)→ $5B(FY27)→ $15B(FY29)**;**非手机收入 $40B by 2029**。

**Dragonfly 路线图 = 两条腿(别混)**:
1. **服务器 CPU(Dragonfly C1000)**:250 核 Oryon(Nuvia 内核)、>5GHz、PCIe Gen7、CXL、**H2 2028 量产**。对标 Amazon Graviton / Ampere / x86。**← Meta 锚在这条**。
2. **AI 加速器(AI200 2026 / AI250 2027 / AI300 2028)**:Hexagon NPU 改;**用 LPDDR 不用 HBM**(见下)。**← HUMAIN + 未具名 hyperscaler 锚在这条**。
3. **软件**:**收购 Modular $39 亿**——直接补此前"没 CUDA 软件护城河"的洞(Modular 做 CUDA 替代栈)。

**客户(已核,硬度分层)**:
- **🟢 Meta(最硬)**:**签了绑定的、跨多代(multigenerational)协议**(非 LOI),**小扎本人视频站台**,原话"Qualcomm will become a data center CPU supplier for Meta"。**是 C1000 服务器 CPU,H2 2028。**
- **🟡 两个 hyperscaler 各 ≥$1B/年、2026 年底起出货**(加速器侧,一个未具名,Morningstar 猜 MSFT/Google)。
- **🟡 HUMAIN(沙特)**:200MW ≈ **$2B**,加速器,2026 起。**主权战略采购,validation 弱于竞争性中标。**

### LPDDR vs HBM:真差异化(且挂上存储周期 thesis)`[KNOWN 2026]`
- AI200 **768GB LPDDR5X = H100 的 10x / B200 的 4.8x 内存**;**单卡装下 400B 参数模型(FP16)**,卡少=通信少=serving 简单。**赌"容量 > 带宽"对推理成立。**
- **代价**:LPDDR 带宽远低于 HBM → token 更慢,**同吞吐要 2-6x 机架**(160kW/机架)。"能效"在占地口径要打问号。
- **存储 thesis 联动**:用 LPDDR **绕开 HBM 售罄(到 2028)+ 高价** = 真供应链 edge;**但这轮全 DRAM 涨价,"便宜内存"优势被部分侵蚀。**
- **结构短板**:高通自框 **$10B 机会/GW**,**对比 NVDA $50B/GW = 只捕获 1/5 $/GW**(芯片便宜、单价低)。**赢份额 ≠ 赢收入。**

### Base rate:"NVDA 杀手"墓地 `[KNOWN]`
- **Graphcore**(2024 $6 亿贱卖软银,Bow IPU 跑不过 A100)、**Habana**(英特尔收,没起来)、**Cerebras/SambaNova/Groq**(niche)。教训:硬件性能 + CUDA 生态双杀。
- **但 QCOM ≠ 初创**:$238B、Hexagon 十年 NPU、现成 hyperscaler 关系。**在"墓地"与"GPU 里的 AMD"之间。关键 nuance:Meta 签的是 CPU(Arm 服务器仗,Graviton 已验证路径,相对好打);真正"干翻 NVDA"的加速器仗仍薄(HUMAIN + 一未具名)。**

### 裁决 + 对组合
- **升级**:从上轮"防守 show-me、不看"升到 **"真期权 + 已有 Meta 硬合同 + 软件补齐"**——比 6/23 卡里"试水期权"强得多。
- **但仍非买点**:① 已部分 price-in(+13%、价 **>** raised FV $200);② $15B 后端押 2028 Meta CPU,芯片还没出货;③ **BofA 只 model FY27-28 每年 $2-5B**(信公司还是信卖方差一倍);④ 对你仍加 betaSOXX 半导体,不补缺口。

### 5 个 upgrade 触发器(预登记,到点重估)
1. **加速器侧硬量产承诺 beyond Meta**:MSFT/Google 出现**具体 $ 订单/PO**(非"will use")。
2. **FY27 实际数 vs $5B 指引**:兑现还是滑(验证后端加载真伪)。
3. **独立 benchmark**:AI250 近内存 >10x 带宽兑现?AI200 的"2-6x 机架"TCO 到底赢不赢?
4. **C1000 服务器 CPU 2028 放量(Meta)**:最大那块的真伪。
5. **估值回到 raised FV($200)以下**才谈安全边际。

## 长期增量（10–20 年）

### 1. “智能终端 everywhere” 平台化

QCOM 最长期的逻辑不是再赢一代手机芯片，而是：

- 所有需要低功耗 AI + 连接的设备，都可能变成它的平台机会

包括：

- 车
- XR
- 眼镜
- 工业终端
- PC
- 机器人边缘计算
- 物联网网关

### 2. 6G / 下一代连接标准

- QCOM 在 4G / 5G 标准上的历史地位，决定了其在 6G 上仍有高概率保持话语权
- 标准迭代意味着：
  - 芯片机会
  - 专利许可机会

### 3. 边缘 AI 普及

如果 AI Agent 真正向端侧和边缘扩散，QCOM 的位置会更有利：

- 它不需要赢下训练芯片
- 只需要赢下`低功耗推理 + 连接`

这比去和 NVDA 正面拼训练卡更现实。

## 风险

- **🔴 China(最大风险,见上方 2026-06 更新)**：~46% 营收且在升 + 国产替代(小米 XRING,自研比例 30%→60%)+ 降价 10-15% + 联发科 + 地缘脱钩尾部(可能永久损失)。**比 Apple 大得多。**
- **Apple 基带自研**：~$75亿/年(~18% 营收)悬崖,2027 归零。已知、已量化、部分已价。
- **手机业务权重仍高**：尽管多元化,QCT Handsets 仍是最大单项;且核心被 Apple+China 两端侵蚀。
- **汽车兑现节奏风险**：增长快但周期长、验证慢;**替换引擎要补 Apple+China 双洞,门槛高。**
- **定制硅执行风险**：数据中心项目若只是试水,重估空间受限。
- **QTL 监管/法律风险**：许可业务受监管和 OEM(尤其中国)议价压力;但 royalty 抗芯片自研替代。
- **价值陷阱风险**：21x 是 cheap-for-a-reason;若替换引擎补不上、handset/中国持续弱 → dead money 数年(但非归零)。

## 估值锚

- 当前 `Forward PE ~22x`
- 对比思路：
  - 高于典型“纯手机周期股”
  - 低于高弹性 AI 芯片叙事股
- 如果市场继续把它当“手机 + 基带”公司，估值上限有限
- 如果市场开始把它当“边缘 AI 平台 + 汽车 + IoT + 定制硅”公司，估值中枢有继续抬升空间

## 结论

QCOM 现在最值得研究的点，不是“手机会不会差”，而是：

`它能不能成功摆脱“手机芯片股”定价框架，重估成“边缘 AI + 连接平台公司”。`

如果你相信：

- 边缘 AI 会持续扩散
- 汽车和 IoT 能兑现
- 数据中心定制硅能打开新估值锚

那 QCOM 依然不是过时资产，而是`中等估值、带平台重估期权的老牌核心半导体公司`。
