# Amazon (AMZN)

## 一句话定位

Agent 时代"对交易抽税赢过广告"的押注。它的广告美元（$700 亿+ TTM）**最抗 agent 化**——贴在交易点上（零售媒体），软件级增量利润率。更狠的是：Rufus/Alexa for Shopping + Buy-for-Me + **把 AI 购物技术开放给第三方零售商** = 把自己做成 **agentic commerce 的基础设施**。无论商品留在 Amazon 还是走 agent，它都抽到税。见框架 [agent 入口](../notes/2026-06-21-agent-era-advertising-entry-point.md)。

## ⭐ 2026-06-24 更新：隐藏的 Anthropic 敞口（你买 AMZN = 间接持有"企业 AI 助手赢家"）

**为什么重要**：美国 AI 普及战里,**消费端 ChatGPT 赢、但企业/编程端是 Claude 赢**(Fortune 100 的 70%、head-to-head 对决赢 ~70%、增速最快)。`[KNOWN 2026]` Claude 的母公司 **Anthropic 是私有、不能直接买**——而 **Amazon 是它最大的外部股东**,所以 **AMZN 是上市标的里最干净的"Claude/Anthropic 代理敞口"**。

**持股规模(实测)** `[KNOWN 2026]`：
- Amazon 累计投入 **$80 亿 + 2026/4 再追加最多 $250 亿**($50 亿当下 + 至多 $200 亿挂钩里程碑)。
- 4 月 filing 账面 **$742 亿**(可转债 $422 亿 + 无投票优先股 $320 亿),对标 Anthropic 2 月 **$3800 亿** Series G。
- **Anthropic 估值已飙到 $9650 亿**(奔 $1 万亿 IPO)→ 按中高 teens 持股比,**Amazon 这笔现值约 $1350–1600 亿** = **AMZN ~$2.6 万亿市值的 ~5-6%,一块没被当主业算的隐藏资产**。

**双重受益**：① 股权升值(Anthropic 估值曲线)② **AWS 托管 Claude**——Anthropic 承诺 10 年 **$1000 亿** AWS 开支 + 年底前 ~**1GW Trainium2/3**(还顺带验证 Amazon 自研芯片)。

**⚠️ 但这是盈利质量旗(必须标)**：`[KNOWN 2026]` Fortune 点出 **Amazon/Google 近期"亮眼 AI 利润"约一半来自 Anthropic 估值上调的账面 mark,不是主业**。含义两面:
- 正面:真实、可能继续升值的隐藏资产;**Anthropic IPO 是 crystallize 催化**。
- 负面:**这是未实现的私有 markup**——它把报告利润撑高、拉低了盈利质量(呼应 [organic-growth-screen](../) 的"别把非经营增长当主业")。Anthropic 一旦 de-rate,这块利润反向蒸发。**看 AMZN 盈利要把这块剥出来看主业。**

## ⭐ 2026-06-24 SOTP 估值 + 三引擎 + capex 矛盾

**核心矛盾(点亮一切)** `[COMPUTED]`：Q1'26 经营现金流 **$1485 亿**,但 **FCF 只剩 $98 亿(0.4% yield)**——因为 **capex 飙到单季 $442 亿(年化 ~$1770 亿)**全砸进 AI 基建。**"AMZN 31x PE 贵"是错觉**:PE 被①零售薄利拉低混合 margin ②$1770 亿 capex 砸低报告利润/FCF 两件事压低。要看清得用 SOTP。

**三引擎(Q1'26 实际)**:总营收 $1815 亿(+17%)、营业利润 $239 亿(margin 13.1%,去年 11.8%)。
| 引擎 | 规模/增速 | 估值估算 `[INFERRED]` |
|---|---|---|
| **AWS** | $376 亿/季,**$1500 亿年化,+28%(15 季最快,reaccelerate)**,~35% OI margin | **~$1.5 万亿** |
| **广告(隐藏软件公司)** | **>$700 亿 TTM,+24%**(Q1 $172 亿),软件级 margin | **~$5500 亿** |
| **零售(NA+国际)** | ~$5760 亿年化(NA +12%/margin 8%→9%、国际 +19%) | **~$4500 亿** |
| **Anthropic 股权** | 现值 ~$1350-1600 亿 | **~$1500 亿** |
| **SOTP 合计** | | **~$2.65 万亿** |

**结论**:**SOTP ~$2.65 万亿 略高于市值 $2.52 万亿 = 公允偏便宜**。市场低估了藏在里面的 **$700 亿/+24% 广告软件公司 + ~$1500 亿 Anthropic 股权**。

**$1770 亿 capex 赌注(最大单一变量)**:多头=AWS reaccel(+28%/15 季最快)在验证需求,capex 见顶后 FCF 反弹;空头=AWS 需求若 disappoint,$1770 亿/年是搁浅成本。**AMZN 已是重资本 AI capex 玩家,不再是轻资本零售飞轮。**

## ⭐ 2026-07-01:收入 vs 利润驱动分离 + margin-later + 大师都不持有

**① 营收结构:收入看零售,利润看云+广告** `[KNOWN 2026]`
| 板块 | Q1'26 营收 | 同比 | 占营收 | 占经营利润 |
|---|---|---|---|---|
| 北美(零售) | $104.1B | +12% | **57%** | 35% |
| 国际(零售) | $39.8B | +19% | 22% | 6% |
| **AWS** | $37.6B | +28% | 21% | **59%** |
| *广告(嵌零售段)* | *$17.2B* | *+24%* | *TTM>$70B* | *高毛利隐藏引擎* |

- **收入 = 零售(NA+国际 79%)**:1P 自营 + 3P 市场(更快/更高毛利)+ Prime。**AMZN 按收入本质仍是零售商**。
- **利润 = 云 + 广告**:AWS 21% 收入却 **59% 利润**;广告软件级毛利。
- **关键:营收由零售量驱动,和内存/AI capex 基本无关 → 营收是最好预测的部分(+15%),被下修的是 EPS/FCF。风险在现金/margin,不在营收。**

**② 2026 全年营收三档 + 下次财报** `[COMPUTED/INFERRED]`
| 情景 | 全年营收 | 增速 | 条件 |
|---|---|---|---|
| 基准 | **~$805–810B** | **+15%** | 与共识 $807–808B 一致 |

**📅 下次财报:2026-07-30(周四盘后),Q2 2026**。分析师 EPS 预期 ~$1.81;公司 Q2 营收指引 **$194–199B(+16–19%)**→ 营收悬念小。**看点三处:① AWS 增速能否守 +28%;② capex 是否再上修(已 $200B);③ 折旧占比(margin-later 炸弹开始不开始显形)。**

**③ margin-later:痛现在在现金,margin 是递延的折旧炸弹** `[INFERRED, 置信 MED-HIGH]`
- **AWS margin 在扩不是压**(Q1'26 ~37.7% 创纪录)——内存 +60~200% 通胀现在 P&L 上看不到。
- **痛全在现金流**:TTM FCF **$26B→$1.2B(塌 95%)**,2026 全年预测 **负 $17B(MS)/负 $28B(BofA)**;2026 capex ~$200B。
- **真 margin 风险递延到 2027–2030**:今天内存撑大的 $200B capex 进资产负债表,按 **5 年折旧**慢慢进 P&L;**Amazon 已把服务器折旧 6→5 年,加速这颗炸弹**。**该怕的情景 = AI 需求消化(存储 glut)撞折旧爬坡 → 营收减速 + 折旧递增 = margin 压缩。**
- 盯:AWS 经营利润率环比拐点 / 折旧占 AWS 营收比 / AI 需求二阶导。

**④ 大师都不持有——不是偶然** `[KNOWN 2026]`
- **巴菲特/伯克希尔**:一直是小仓 + **非本人选**(2019 Combs/Weschler 建);**2025Q4–26Q1 砍 ~77%**(1000万→~230万股),方向退出(一源称已清)。
- **段永平**:**从未持有**。其组合 = Apple(第一)/NVIDIA(暴增至第三)/PDD/特斯拉(新建)/Alphabet,**无 AMZN**。
- **判断**:两位 owner-earnings 派都避开/退出 Amazon **不是偶然**——AMZN 最难用"股东盈余"估值(巨额 capex + 折旧口径可调 + **FCF 塌到转负**,账面利润与现金利润长期背离)。**买 AMZN = 买"再投资复利"的信仰,不是段永平式"算得清的便宜好生意"。分歧不在营收(好预测),在"赚的钱看不看得清"。** 呼应本卡 Anthropic markup 盈利质量旗 + [organic-growth-screen](../)。

## 护城河类型

**交易通道 + 零售媒体 + AWS 规模**：

- **交易通道（agent-proof 核心）**：目录 + 履约 + 支付 + Prime。agentic commerce 再聪明也要走一条交易轨道，而这条轨道是 Amazon 的。
- **零售媒体**：广告贴在购买意图/交易点，最难被 agent 绕开（vs 搜索/社交广告）。
- **AWS 规模**：云第一 + $3640 亿 backlog，AI 工作负载的承载层。

## 市场隐含假设 vs 我的分歧 ⭐

> **市场在 price in 什么**：~30x，隐含 AWS 重新加速 + 零售利润率扩张 + 广告高增。**市场主要把 AMZN 当 AWS 故事在定价。**

**我可能与市场不同的地方**：
1. **市场低估"交易抽税"的 agent-proof 属性**：AMZN 的广告美元贴在交易点，是所有广告里**最难被 agent 中介掉的**。更关键——它把 Rufus 的 AI 购物技术**开放给第三方零售商**，意味着它不只想赢自家电商的 agent，而想做**所有 agentic commerce 的底层轨道**。商品留在 Amazon→抽零售+广告；商品走第三方 agent→抽基础设施费。**两头通吃。**
2. **这是"抽成经济 > 广告经济"框架的最佳实体**：当 agent 替你下单，价值从"影响你"（广告）转到"完成交易"（抽成），而 Amazon 是抽成轨道的天然所有者。

**我哪里可能错（证伪条件）**：
- **AWS 才是股价真驱动**：广告/agent thesis 再对，若 AWS 减速或 AI capex blink，股票照跌——别把"agent 入口"当成 AMZN 的主矛盾。
- **"沦为哑管道"风险**：中立超级 agent（ChatGPT/Apple）成为购物门口、骑在 Amazon 之上，把 Amazon 降格为只做履约（商品化低利润）。这是 Amazon 版的"被入口架空"。
- **估值**：~30x 已 price in AWS 加速 + 利润率扩张。

## 短期增量（3–5 年）

- AWS 重新加速（+28%，15 季最快）+ $3640 亿 backlog + Anthropic $1000 亿。
- 广告 +24% 高增、软件利润率拉动盈利。
- Rufus/Buy-for-Me 把 agentic commerce 货币化（已 ~$120 亿增量销售）。

## 长期增量（10–20 年）

- 若成 agentic commerce 的基础设施轨道（第三方零售商也用它的 AI 购物技术）→ 对交易抽税的收税口。
- AWS 承载 AI 推理长期需求 + 自研芯片（Trainium/Inferentia）成本优势。

## 风险

- **⚠️ 被中立超级 agent 架空（首要）**：ChatGPT/Apple 成购物门口，Amazon 降格哑管道。
- **AWS 减速 / AI capex 见顶**：股价真驱动，与你半导体书的共同风险。
- **⚠️ Anthropic markup 反转**：隐藏资产升值在撑报告利润(近半 AI 利润来自此 mark);Anthropic 若 de-rate,利润反向蒸发 + 盈利质量被重估。
- **监管**：反垄断（捆绑/自营优先）。
- **估值**：~30x，安全垫薄。

## 估值锚

- **用 SOTP 看(非 PE)**:AWS ~$1.5万亿 + 广告 ~$5500亿 + 零售 ~$4500亿 + Anthropic ~$1500亿 ≈ **$2.65 万亿,略高于市值 = 公允偏便宜**。31x PE 是零售薄利 + capex 砸低利润的错觉。
- 类比：[GOOGL](GOOGL.md)（意图广告 vs 交易抽税，互补；corr 0.44）。
- **⚠️ 订正"低相关"旧说**:实测 corr NVDA 0.32/GOOGL 0.44/META 0.47/SOXX 0.35,betaSOXX 0.27 —— **它已是 AI capex 大花钱方,坐在 AI 簇里,不是分散腿**。加 AMZN ≠ 降集中度(对比 NFLX 0.05/NOW -0.07 才是真正交腿)。

**⭐ 关键(资本保全相关)**:**悲观档不是崩盘,是"原地踏步"(+2%/年、$258 仍高于现价)**——因为 SOTP 有地板(AWS+广告+Anthropic+零售都是真生意真现金)。**形状=赢了 +15~27%/年、输了 treading water +2%**,不是"翻倍 vs 腰斩"。比 AI 书里 NVDA/MRVL/CRCL(悲观档 -40~60%)的风险收益形状好得多——下有底、上有弹,对"宁愿错过不损失本金"对路。

**警告**:乐观档 $7.46万亿=史上最大公司(大 ask,非基准);Anthropic 那块波动极大且是未实现 markup(可逆);4.5 年 LOW 置信,衰退/反垄断/AI 资本周期反转任一可击穿地板。**别盯 2030 的数,盯每季 AWS 增速 + FCF 何时反弹——它逐季告诉你滑向哪一档。**
