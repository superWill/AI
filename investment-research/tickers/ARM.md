# Arm Holdings (ARM)

## 一句话定位

全球指令集架构（ISA）垄断的收税口：几乎每一颗手机 SoC、越来越多的数据中心 CPU（Grace/Axion/自研 Arm）、边缘 AI、汽车都在它的指令集上跑，按芯片出货抽版税。与 [SNPS](SNPS.md)/[CDNS](CDNS.md) 同属"产业链最上游、不造芯片只收税"的极致形态——但 Arm 多一层**版税率本身在抬升**的引擎（Armv9 + CSS 把单芯片抽成翻倍）。

## 护城河类型

**指令集垄断 + 切换成本 + 版税复利**：

- **生态锁定**：全球开发者/工具链/软件栈围绕 Arm 指令集构建，迁移 = 重写整个软件世界，成本以"行业-十年"计。
- **双寡头都绕不开**：手机 100%、数据中心份额上升（Nvidia Grace、Google Axion、AWS Graviton、微软 Cobalt 全是 Arm）。
- **版税率抬升引擎（区别于纯 IP 公司的关键）**：Armv9 单芯片版税率约为 v8 的 ~2x；CSS（Compute Subsystems，卖"半成品计算子系统"而非单纯指令集）把抽成进一步上移。这是"量 × 价"双复利，手机时代的 Arm 只有量。

## 市场隐含假设 vs 我的分歧 ⭐

> **市场在 price in 什么**：~90x+ 远期把"数据中心 Arm 份额持续抢占 x86 + 版税率随 v9/CSS 结构性抬升"当成**近乎确定且巨大**。当前价隐含未来 ~10 年版税量价双击不出错。

**我可能与市场不同的地方（需验证才算 edge）**：
1. **版税率的二阶导**——市场盯"份额"，真正的杠杆是**单芯片抽成**。如果 CSS 从 20% 一路爬到 40%+、v9 渗透率冲顶，版税收入可以在出货量平的情况下继续两位数增长。这是数据中心份额叙事之外、被讨论不足的引擎。
2. **Arm 自己下场造芯片（chiplet/CSS 整机）**——若兑现，抽成口径从"每核几美分"跳到"每套子系统几十美元"，是重定价级别的变化。

**我哪里可能错（证伪条件）**：
- **数据中心 Arm 份额停滞**：定制 ASIC 虽用 Arm 但走**架构授权低版税**口径；若数据中心增量大头是低抽成的 ASIC 而非高抽成的 CSS，"份额涨、抽成不涨"，90x+ 崩。
- **Arm 造芯片 = 与客户竞争**：得罪高通/联发科/苹果等被授权方，反噬授权盘。
- **估值**：即使 thesis 全对，90–180x 远期意味着你在为完美定价付钱，5 年远期回报大概率被透支。

## 短期增量（3–5 年）

- v9 渗透率继续爬 + CSS 占比上行 → 版税率结构性抬升。
- 数据中心版税（已翻倍）随 Grace/Axion/Graviton/Cobalt 放量持续高增。
- 边缘 AI / 物理 AI（端侧推理、机器人 MCU）打开新出货品类。

## 长期增量（10–20 年）

- "所有计算的指令集底座"——从手机扩到数据中心 + 汽车 + 机器人 + 端侧 AI。
- 若 Arm 上移到 chiplet/整机子系统，抽成口径整体跳档。

## 风险

- **⚠️ 估值（首要、且贵在明处无垫）**：~90x+ 远期，卖方均值目标低于现价 38%。
- **造芯片反噬授权盘**：与被授权大客户正面竞争的治理风险。
- **Arm China 治理黑箱**：合资公司控制权历史遗留，中国敞口政策化。
- **高通诉讼/授权摩擦**：架构授权 vs ALA 口径的法律拉锯。
- **周期**：手机出货是版税基本盘，消费电子周期下行直接压版税。

## 估值锚

- 类比：[SNPS](SNPS.md)/[CDNS](CDNS.md)（同为上游收税口，但 EDA 远期 ~27–48x，Arm 90x+ 是另一个量级）。
- 远期 90x+ 对应版税 +21%/授权 +25%——**质量极高但定价已透支多年**。
- "伟大的收税口，灾难性的价格"——典型好公司烂价格，等大幅回撤才有赔率。

### Reverse DCF —— 把"贵"变成数字 ⭐（2026-06-21 测算）

> 输入：EV ≈ $417B（市值 $421B − 净现金 ~$3.6B）；FY26 非 GAAP FCF = **$882M**（R&D +43% 压低了基数）；r = 10%；终值增速 3%；10 年显式期。

| 口径 | EV/FCF | **市场隐含 FCF 十年 CAGR** |
|---|---|---|
| 当前 FCF $0.9B（R&D 高峰压低） | **~463x** | **~50–52%** |
| 正常化 FCF ~$1.5B（R&D 摊薄后） | **~278x** | **~44%** |

**翻译**：当前价隐含 Arm 要 **连续十年 FCF 复合增速 ~44–52%**。而卖方未来 3 年营收预期仅 **~27%**。两者的差 = 市场押注 **"营收 ~27% + 利润率连续十年大幅扩张"同时发生整整十年**。
- 对照：净利润过去 3 年 CAGR 仅 13%；未来 4 年预期 53%（低基数）。市场实质把这段 4 年的超高速**外推到 10 年**。
- r 提到 11%（高 beta 更合理）隐含增速更高。**这是负安全垫的量化证据,不是形容词。**

## 退出条件

- 触发卖出：数据中心 Arm 份额见顶 + CSS 占比停滞（量价双击证伪）。
- 触发减仓：估值进一步抬升而版税增速放缓（PEG 恶化）。
- 再加码：AI 板块系统性恐慌把远期打回 ~40–50x（回到 EDA 量级）才进核心。
