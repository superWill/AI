# Meta Platforms (META)

# 一句话定位

社交/注意力广告的在位者，回答"社交 + 搜索"里**社交那一半**。核心反直觉：**对 Agent，注意力广告是受冲击最小的一端**（人为娱乐而刷，不为 agent 而刷），**且当下被 AI 直接做大**（Andromeda/Advantage+ 让广告 +33%，eMarketer 预测 2026 底**首次超过 Google** 全球广告）。这是全广告业**最被验证的 AI 变现**——别人是"未来 AI 故事"，Meta 是"AI 现在就在印钱"。代价：天量 capex + Reality Labs 黑洞 + 最弱的 agent 入口位。

> 📝 **修正**：上一版框架把 Meta 当"弱主角"。数据打脸——它是**近期 AI 广告最强赢家**，只是**长期 agent 入口最弱**。两件事都对。

## 护城河类型

**网络效应 + 注意力 + AI 广告闭环**：

- **网络效应**：35 亿+ 日活跨 FB/IG/WhatsApp/Threads，社交图谱锁定。
- **注意力（agent-resistant）**：娱乐刷流不被 agent 中介——你不会让 agent 替你刷短视频。
- **AI 广告闭环**：自有数据 + Llama + Andromeda → 定向/创意/出价全自动化，广告主 ROAS 提升 = 提价权。

## 市场隐含假设 vs 我的分歧 ⭐

> **市场在 price in 什么**：~22–25x，定价广告机器 + **因 capex 暴增而打折**（财报后曾因 capex 担忧下杀）。

**我可能与市场不同的地方**：
1. **市场盯 capex 的"花"，低估 AI 在核心已"印"**：广告 +33%、曝光 +19%、单价 +12%、广告主 AI 工具采用翻倍——**这是全广告业唯一已兑现的 AI 变现闭环**，不是 PPT。市场把它和"未来 AI 故事"的同行一起折价，错配。
2. **Agent 冲击次序被忽略**：agent 先杀搜索意图，**社交注意力最后才轮到**。近期 Meta 是 AI 广告**最安全 + 最快**的一端——与直觉相反。

**我哪里可能错（证伪条件）**：
- **capex ROI（首要）**：$1250–1450 亿 + "Superintelligence Labs" 是扎克伯格的超级豪赌；不兑现则 FCF 崩。市场的担忧不是无的放矢。
- **Reality Labs 无底洞**：$835 亿累计亏损仍 ~$40 亿/季。
- **长期 agent 入口最弱**：Meta 没有"做事入口"（Meta AI 消费端弱于 ChatGPT）；若交互迁移到 agent，信息流广告长期被侵蚀。
- **监管**：反垄断、青少年安全、隐私。

## 短期增量（3–5 年）

- AI 广告（Andromeda/Advantage+）持续提 ROAS → 量价双升。
- 有望 2026 底超 Google 成全球第一大广告平台。
- WhatsApp 商业消息 + 点击到消息广告变现。
- Meta AI（端到 35 亿用户的分发）+ AI 眼镜（MR 眼镜推迟到 2027，转 AI 眼镜）。

## 长期增量（10–20 年）

- 若 Meta AI 借社交分发成消费 agent 入口 → 补上最弱的一环。
- AI 眼镜若成下一代设备入口 → 自有硬件分发（绕开 Apple/Google）。

## 风险

- **⚠️ capex ROI（首要）**：$1250–1450 亿超级豪赌，回报未证。
- **Reality Labs 黑洞**：~$40 亿/季持续失血。
- **长期 agent 入口最弱**：无"做事门口"，信息流长期被 agent 侵蚀风险。
- **监管**：反垄断/青少年/隐私。
- **估值**：~22–25x，相对不贵但 capex 是悬顶。

## 估值锚

- 类比：[GOOGL](GOOGL.md)（同广告巨头，但 META corr 仅 0.23——并不同步）、其他大盘 AI。
- ~22–25x 对应广告 +33%——**剔除 capex 担忧其实便宜**；capex 兑现则重估向上。
- **组合角色**：betaSPY 1.50 + corrSOXX 0.30，又一条与半导体书低相关的变现腿（可与 GOOGL/AMZN 轮动配置）。

## 退出条件

- 触发卖出：capex 暴增但广告增速 + ROAS 不兑现（豪赌失败）。
- 触发减仓：信息流被 agent 实质侵蚀 + Reality Labs 失血扩大。
- 再加码：AI 广告持续兑现 + capex ROI 显现 + 板块恐慌错杀。

## 跟踪信号

- **广告营收增速 + 曝光/单价拆分**（AI 变现闭环的核心读数）
