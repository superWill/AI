# ServiceNow (NOW)

## 一句话定位

企业工作流的 **system-of-record / system-of-action**。市场把它当"按座席收费、要被 AI agent 颠覆的 SaaS"杀了 -52%；**我的分歧:它是 agentic 企业的编排层——agent 要在一个系统里"干活",那个系统就是 ServiceNow,座席可能缩、但 agent 的活落在它平台上、用消费式定价收回来。** Q1'26 beat + 上调指引 + Now Assist ACV 冲 $15 亿,说明它目前在赢这个转型,不是输。

## ⭐ 核心命门：座席 SaaS 会被 AI agent 颠覆吗？

**熊论(已 price 进 -52%)** `[INFERRED/KNOWN]`：
- 座席制 = 按人头/许可证收费。若 AI agent 替代人力 → 需要的人类座席减少 → 座席收入萎缩。整个 SaaS 板块(NOW corr **CRM 0.78**)因此被 de-rate。
- Klarna 等公开宣称用 AI 砍 SaaS 用量;Benioff 把 Salesforce 改口"Agentforce"按对话/结果收费 = 默认座席有risk。

**牛论(我的分歧)** `[KNOWN 2026]`：
- **NOW 不是"给人打字的座席工具",是工作流编排平台**——agent 要在一个 system-of-action 里执行,那个系统就是 ServiceNow(8400 家企业、深度集成、切换成本)。
- **它已转"AI-native 消费式定价"**:"用得越多、消耗的 assist 越多"——**按 AI 用量收,不按人类座席**。Now Assist 2026 ACV **从 $10 亿目标上调到 $15 亿**;花 $100 万+ 的客户 **+130% YoY**;含 3+ 个 Now Assist 产品的单子 **+70%**。
- **"AI 变现正在向拥有工作流层的平台集中"**——agent 做的活落在 NOW 上 → **座席缩、agent 的价值它照样抽**。平台在 agentic 世界更中心,不是更边缘。

**反向 DCF:市场 price-in 什么** `[COMPUTED]`（$99B / FCF $51 亿，Gordon 3%）:

| 折现率 | 隐含 10y FCF CAGR |
|---|---|
| 9% | 4.6% |
| **10%** | **6.7%** |
| 11% | 8.7% |

→ **市场只给 ~6.7% FCF CAGR**——把"AI 杀 SaaS、增速塌到中个位数"完全计入。对一个**营收还 +22%、上调指引、AI ACV +50% 上修**的公司,**bar 低到失真**。这就是分歧机会:若消费转型成立(Q1 证据指向成立),6.7% 是错杀。

**我哪里可能错(证伪条件)**：
- **转型尚早**:若**座席侵蚀快于 AI 变现**,或消费定价 1:1 蚕食座席收入(净增量为零),-52% 就是公允。
- 有怀疑者(diginomica/Zavery)质疑 outcome-pricing 是否真落地。
- 一个 22% 增长被重定价到 6.7% 隐含,可能市场看到了结构性的东西(整个座席 TAM 按人头算、AI 压人头)。
- **和 SaaS 板块同涨跌(corr CRM 0.78)**:若整个软件继续 de-rate,它跟着跌(虽对你半导体书无关)。

### 转型记分卡(2026-06-24 验证：现在在赢,熊 price 的是未来)`[KNOWN 2026]`

| 读数 | 当前 | 信号 |
|---|---|---|
| **Now Assist ACV** | 2025 底 $6 亿→Q1'26 **$7.5 亿**(单季+25%,Q4 net-new 翻倍);目标 $10亿→**上修 $15亿** | 🟢 消费变现加速 |
| **活跃座席增速** | **+25%** | ⚠️ **熊的引信:何时从 +25% 转 0/负** |
| **非座席 ACV 占比** | **>50%** net-new(token/连接/用量) | 🟢 座席见顶时要靠它接 |
| **续约率 / cRPO** | **97%** / cRPO $126亿 **+22.5%** | 🟢 零侵蚀迹象,前瞻订单 >20%(非 6.7%) |
| **防蚕食机制** | AI 捆进座席 **+60% 溢价** + 消费封顶 overage(vs Salesforce 纯消费蚕食自己) | 🟢 座席略减也靠 ARPU 抬升补 |

**熊的催化(杀到 19x 的原因)**:KeyBanc 罕见 Underweight("seat count crisis"1月)、**UBS 4/10 降级**(AI=座席模型结构逆风)。McDermott 自证讽刺:"AI 提效,空缺岗不回填"——CEO 自己用 AI 减人头,验证熊的大前提,只辩"定价能扛"。

**读法**:**现在(座席+25%/续约97%/cRPO+22%/ACV加速)完全无座席崩塌迹象,牛论逐季兑现;熊 price 的是"未来 AI 全行业砍人头时,座席增速转负、消费 ACV 能否接住"——尚未被测试。** 19x 把未发生的崩塌完全计入。**真正引信=活跃座席增速**:只要还 +25% 且非座席 ACV >50% 在涨,即错杀;座席转负而消费没接住,熊就对。

## 护城河类型

**工作流 system-of-record + 编排层 + 切换成本**：
- 8400+ 企业,跨 IT/HR/客服/安全的工作流中枢,深度嵌入 = 高切换成本。
- agentic 世界的"控制塔":AI agent 需要一个有权限、有记录、能执行的系统去干活 → NOW 是天然落点。
- 消费式定价让它**从座席模型迁移到用量模型**,把颠覆变成顺风。

## 短期增量（3–5 年）
- Now Assist ACV $15 亿 → 继续上修;消费定价放量。
- FY26 订阅 +21% 固汇;$1M+ AI 客户 +130%。
- 跨 IT/HR/客服的 agent 编排 SKU 渗透。

## 长期增量（10–20 年）
- 成为"AI agent 劳动力"的管理/编排标准层 → 用量经济长期复合。
- 若座席→消费迁移成功,TAM 从"人头数"扩到"agent 活动量"(可能更大)。

## 风险
- **⚠️ 座席侵蚀 > AI 变现(首要)**:转型早期,若净增量证伪,de-rating 公允。
- **消费定价未证**:outcome-pricing 真实性有疑。
- **SaaS 板块系统性 de-rate**:corr CRM 0.78,跟跌。
- **估值非地板**:19x 比历史便宜但非 dirt cheap;GAAP 利润率被 SBC 压低(看现金流/非 GAAP)。

## 估值锚
- forward **19.1x**(历史 50-60x)、P/FCF 19.4x、FCF yield 5.2%、净现金。反向 DCF 隐含 ~6.7% CAGR = 低 bar。
- 锚:不是"捡漏",是"**AI 杀 SaaS 恐慌错杀的工作流龙头**"——成立与否取决于消费转型 vs 座席侵蚀的赛跑。Q1 证据偏牛。

## 退出条件
- 触发观望→放弃:连续 2 季 Now Assist ACV 上修停滞 + 座席净收入转负。
- 触发买入/加码:消费定价 ACV 持续超预期 + 板块恐慌进一步错杀(20x 以下 + 增速维持)。
- 证伪:净收入留存率(NRR)结构性下台阶 = 座席侵蚀坐实。
