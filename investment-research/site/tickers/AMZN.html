Amazon (AMZN)

一句话定位

Agent 时代"对交易抽税赢过广告"的押注。它的广告美元（$700 亿+ TTM）最抗 agent 化——贴在交易点上（零售媒体），软件级增量利润率。更狠的是：Rufus/Alexa for Shopping + Buy-for-Me + 把 AI 购物技术开放给第三方零售商 = 把自己做成 agentic commerce 的基础设施。无论商品留在 Amazon 还是走 agent，它都抽到税。见框架 agent 入口。

  • AWS 环比：Q1 +$20 亿 → Q2 +$46.5 亿 → Q3 +$37.5 亿（环比 +8.9%，Q2 +12.4%）。同比从 37% 加速到 39% 有一半是去年 Q3 基数低（Q3'25 环比只 +6.9%）。同比加速、环比增量缩小同时成立。
  • AWS 成本：营业费用 +30.8% vs 收入 +39.3% → 增量利润率 48.8%；tech & infrastructure 合并费用 $348.1 亿 +20.2%（占销售 17.2% vs 16.1%）。

  • 有机 vs 买来：全部有机（并购现金 9M 大项是非上市投资不是并表）。AWS 增量里 durable（企业上云/推理）vs 项目型（给一两家实验室的 GW 级预留容量）的拆分公司不给；Jassy 说大客户「hundreds of megawatts or sometimes up to a gigawatt」提前预留 (2手)——这部分和 GOOGL 的 TPU 整机一样是「一个客户的 capex 周期」。

六点读法：

  1. OCF 没问题，问题全在 capex 一行。 OCF +19%、净利持平（去年含 mark），D&A +$41 亿、递延税 +$50 亿撑住；营运资金 Q3 净流出 $103 亿（存货 −$45 亿为旺季备货、应收 −$21 亿）。应收账款年初 $677 亿 → $982 亿（+45%），TTM 销售只 +15%——DSO 在拉长，是 AI 实验室客户的账期还是零售季节性，10-Q 待核 [KNOWN, HIGH 数字；原因 UNKNOWN]。
  2. 融资结构实况：Q3 缺口 $335 亿 + 非上市投资 $240 亿（投资现金流「acquisitions / non-marketable investments」Q3 −$239.9 亿，大概率含 Anthropic 4 月追加 [INFERRED, MED]）= $575 亿；用 $481 亿新债 + 消耗现金 $222 亿填。9 个月发债 $1,151 亿（Q1 ≈ $534 亿 / Q2 $136 亿 / Q3 $481 亿，由 Q2、Q3 新闻稿差额推），2025 全年 ≈ $157 亿（前 9 月 $7.5 亿 + Q4 ≈ $149 亿，TTM 差额推）→ 7 倍以上。 [COMPUTED, HIGH] 已核到 8-K 的只有 7/9 美元 $249.2 亿（8 档：浮息 + 2029–2066）和 9/14 英镑 £42.4 亿（≈ $57 亿 [GUESS 汇率]），Q3 $481 亿里还有 ≈ $175 亿没在 8-K 索引里找到对应发行（可能是非注册/其他币种，10-Q 待核）。
  3. ⑥-a 四家对照：GOOGL = ATM 发股 + 债、回购零；META = Class C 发股；TSLA = 下调 capex；AMZN = 纯发债、不发股、回购零、股数 +1.2%（SBC）。AMZN 是四家里对股东最不稀释、对债权人最激进的一个：净现金年初 +$574 亿 → 9 月末净债 −$589 亿，一年内翻 $1,160 亿。利息现金支出年化已 ~$47 亿（扣资本化后），资本化利息本身是另一笔 P&L 遮挡，10-Q 待核。
  4. Q4 算术：若 capex 指引守住 → Q4 净 capex ≈ $478 亿；Q4 OCF 季节性最强（Q4'25 TTM 跳 +$88 亿），按 $600–700 亿估 → Q4 FCF 转正 +$120~220 亿，2026 全年 FCF ≈ −$360~−$460 亿。若 Q4 capex 实际 $650–750 亿（延续 Q3 节奏）→ Q4 FCF ≈ 0 ~ −$150 亿，2026 全年 ≈ −$600~−$730 亿、全年 capex ≈ $2,370–2,470 亿。哪个成立，决定「$2,200 亿不变」是真指引还是过时数字。 [COMPUTED, MED]
  5. 2027 算术：capex「meaningfully more」按 +20–35% = $2,650–2,970 亿；OCF 按 +20% ≈ $2,000–2,100 亿 → 2027 FCF ≈ −$600~−$950 亿，发债需求与 2026 同量级。「We can fund this plan」在这个算术下的意思是「债券市场继续买」——7/9 那笔 8 档一次卖 $249 亿、含 2066 年 40 年期，说明现在确实买得动。 [COMPUTED, LOW-MED]
  6. 折旧滞后（裂缝 1 的数字）：D&A +25% vs 净 P&E +42.5%（年初 $3,570 亿 → $5,089 亿）；D&A 占销售 10.4%（去年 9.3%）。P&E 增量 $1,519 亿里按服务器 5 年 / 数据中心 ~10 年摊，稳态 D&A 年增量 ≈ $250–300 亿，相当于 2027 合并销售的 ~3pt、AWS 销售的 ~7–10pt（若 2/3 落 AWS）——6/24、7/1 写的「margin-later 折旧炸弹」现在有了数量级。新闻稿只给合并 D&A，不给分部 D&A、不给使用年限变化；Jassy 电话会说「finding ways to extend useful lives」+ 芯片「5–6 年」(2手)——与 2025 年服务器年限 6→5 年的方向相反，若 10-Q 披露年限延长 = 利润率有会计顺风，AWS 38.7% 的成色要再打折。 [COMPUTED, MED；年限变化 UNKNOWN，10-Q 待核]

市场隐含假设 vs 我的分歧 ⭐

市场在 price in 什么：~30x，隐含 AWS 重新加速 + 零售利润率扩张 + 广告高增。市场主要把 AMZN 当 AWS 故事在定价。

我可能与市场不同的地方：

  1. 市场低估"交易抽税"的 agent-proof 属性：AMZN 的广告美元贴在交易点，是所有广告里最难被 agent 中介掉的。更关键——它把 Rufus 的 AI 购物技术开放给第三方零售商，意味着它不只想赢自家电商的 agent，而想做所有 agentic commerce 的底层轨道。商品留在 Amazon→抽零售+广告；商品走第三方 agent→抽基础设施费。两头通吃。
  2. 这是"抽成经济 > 广告经济"框架的最佳实体：当 agent 替你下单，价值从"影响你"（广告）转到"完成交易"（抽成），而 Amazon 是抽成轨道的天然所有者。

我哪里可能错（证伪条件）：

  • AWS 才是股价真驱动：广告/agent thesis 再对，若 AWS 减速或 AI capex blink，股票照跌——别把"agent 入口"当成 AMZN 的主矛盾。
  • "沦为哑管道"风险：中立超级 agent（ChatGPT/Apple）成为购物门口、骑在 Amazon 之上，把 Amazon 降格为只做履约（商品化低利润）。这是 Amazon 版的"被入口架空"。
  • 估值：~30x 已 price in AWS 加速 + 利润率扩张。
