关键点：人形机器人（Tesla Optimus / Figure / 1X 等）每个机器人需要 20–40 个谐波减速器。 按 Tesla 目标 2027 量产 50,000 台计算，仅 Tesla 一家就需要 100–200 万个谐波减速器/年。 当前 Harmonic 全球年产能仅 200–300 万个。

护城河类型

工艺壁垒 + 制造门槛型护城河（最深的一种）：

  • 谐波减速器 = 柔轮 + 刚轮 + 波发生器三件套
  • 柔轮的弹性变形循环寿命要求 10^8 次以上 → 钢材热处理 + 精密加工工艺
  • 30+ 年工艺积累 + 客户验证周期长（每个新设计要测试 1–2 年）
  • 客户切换成本极高 → ABB / Fanuc / Yaskawa / KUKA / Universal Robots 30+ 年合作
