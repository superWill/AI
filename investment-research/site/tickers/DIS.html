The Walt Disney Company (DIS)

一句话定位

"IP 飞轮"的范本：一套角色/故事(Marvel/Star Wars/Pixar/迪士尼动画)创造一次，跨电影→流媒体→乐园→邮轮→周边→游戏反复变现。在"agent 通缩内容、通胀 IP×在场"框架里——当 AI 让通用内容无限且免费，被深爱的 IP + 可信品牌 + 物理乐园的相对价值反而上升。但它不是纯轻资产：IP 是轻资产皇冠，利润引擎(乐园)却超级重资产。准确说法 = 轻资产 IP 给重资产乐园定价权。

关键：迪士尼不是迪士尼乐园那种重资产的反面——它的利润大头恰恰来自重资产乐园。框架的真相是：IP 让重资产值钱(人均消费 +5%、定价权)，但你买的仍是一个资本密集的乐园生意，外面包了层 IP。别当纯授权股估。

护城河类型

IP 飞轮 + 品牌信任 + 物理乐园：

  • IP 飞轮（核心）：百年角色库，跨媒介复用，创造一次无限变现——AI 生成不出"米老鼠/钢铁侠"这种被几代人深爱的 IP。
  • 品牌信任（抗 AI slop）：家庭安全、可信——当 AI 内容泛滥、信任崩塌，"迪士尼出品"是稀缺的信任标签。
  • 物理乐园（agent-proof）：在场体验无法委托、无法生成；IP 给它定价权。

市场隐含假设 vs 我的分歧 ⭐

市场在 price in 什么：~17–18x，定价"转型中的媒体公司"(线性电视衰退 + 流媒体追赶)，且因 2021 后屡次失望而给折价。

我可能与市场不同的地方：

  1. 市场用"衰退的旧媒体"框架估它；我用"agent 时代最稀缺组合"框架：被深爱的 IP + 品牌信任 + 物理在场——这是 AI 浪潮里最难被复制的三件套。AI 通缩通用内容,恰恰抬高这三者的相对价值。 市场没给这个"反 AI 周期稀缺性"溢价。
  2. 两个转折正在兑现:流媒体首次破双位数利润率(转型在 work)、乐园定价权(人均 +5%)。~17x 给一个 EPS 增 12–16% + 双转折的公司,比它的质量便宜。

我哪里可能错（证伪条件）：

  • 不是轻资产（首要诚实点）：利润 57% 来自资本密集的乐园;消费衰退直接砸利润引擎,且未来十年 ~$600 亿乐园 capex 是大 ROIC 赌注。
  • 线性电视(ESPN/网络)持续衰退拖累。
  • 执行记录差：2021 后内容屡失手、CEO 接班反复——这是"质量打折"的真实来源,不全是错杀。
  • AI 侵蚀内容侧：下一代在 AI 生成内容里长大,经典 IP 的代际黏性是否延续?

短期增量（3–5 年）

  • 流媒体利润率爬坡(破 10% → 继续扩)。
  • 乐园定价权 + 新邮轮/园区扩建(IP 拉动人均消费)。
  • IP 飞轮:新片→流媒体→乐园联动变现。

长期增量（10–20 年）

  • AI 个性化 IP 体验(用 AI 把经典 IP 做成千人千面的互动/沉浸)——"西部世界"方向里它握最好的 IP 弹药。
  • 体验经济占比提升 + IP 跨界(游戏/授权)。

风险

  • ⚠️ 重资产 + 消费周期：利润引擎是乐园,衰退期承压;$600 亿 capex ROIC 待证。
  • 线性电视衰退:结构性逆风。
  • 执行/接班:历史失望的来源。
  • AI 侵蚀内容 + 代际 IP 黏性:长期不确定。
  • 估值:~17x 不贵,但"便宜"部分反映了执行折价。

估值锚

  • 类比:NFLX(纯流媒体,更贵)、LYV(纯在场,更纯但更窄)。DIS = IP + 在场 + 流媒体三合一,但夹着线性电视拖累。
  • ~17–18x forward 对应 EPS +12~16% + 双转折——质量与价格错配,偏低估。
  • 组合角色:beta 0.85 + corrMU 0.03,与 LYV 同属反 AI 周期腿(两者互相 corr 0.30);比 LYV 多元(IP+流媒体),法律尾部风险小得多。

退出条件

  • 触发卖出:乐园利润 + 人均消费同时转弱(定价权=IP 强度的读数破了) + 流媒体利润率回落。
  • 触发减仓:消费衰退 + capex ROIC 不及预期。
  • 再加码:流媒体利润率持续扩 + 乐园定价权延续 + 执行兑现去折价。

跟踪信号

  • Experiences OI + 国内人均消费（IP 定价权 = IP 强度的核心读数）
  • 流媒体利润率(≥10% 目标能否持续扩)
  • 乐园 capex ROIC(~$600 亿十年计划)
  • 内容片单命中率 + 线性电视降幅
  • IP 代际黏性(新一代是否仍买账)
