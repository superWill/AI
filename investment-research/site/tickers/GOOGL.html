护城河类型

默认分发 + 数据 + 全栈（模型→芯片→分发→支付）：

  • 分发是真护城河：Android(数十亿) + Chrome + 默认搜索位——agent 时代入口之争，谁占设备默认位谁占先手。
  • 全栈自研：Gemini 模型 + 自研 TPU（成本/算力自主）+ 云 + 广告网络 + 支付——闭环。
  • 数据飞轮：搜索/地图/YouTube/Android 的意图与行为数据，喂养 agent 的差异化。

市场隐含假设 vs 我的分歧 ⭐

市场在 price in 什么：低 20x + $4.49T，隐含"Google 成功转型 + 云/Gemini 抵消搜索风险"。市场已不再定价"AI 杀搜索"（熊市叙事在退）。

我可能与市场不同的地方：

  1. 熊市叙事被证伪是近期事实，但真正的威胁是二阶的：即便 AI Overviews 今天能变现，长期风险是独立 agent（ChatGPT）成为做事的门口，把入口从 Google 的"面"上迁走；且单答案 agent 的单位经济结构性低于十链拍卖（一个答案 vs 一页广告位）。问题不是"搜索今天死不死"，是"Google 能否用分发在入口迁移前先锁住 agent"。
  2. AEO 取代 SEO 的话语权：谁控制 agent 候选集谁对品牌有定价权。Google 若把 Gemini 做成默认入口，它就从"卖搜索位"升级为"卖 agent 候选集"——重定价向上，而非向下。

我哪里可能错（证伪条件）：

  • 搜索营收增速转负：AI Overviews 蚕食自家高利润广告位（创新者窘境兑现）。
  • Gemini 消费端输给 ChatGPT：入口迁移到 Google 面之外，分发优势作废。
