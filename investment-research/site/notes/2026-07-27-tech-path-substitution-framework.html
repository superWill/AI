技术路线替代的判据框架

一句话

当期市场份额对路线胜负的信息量接近零；决定胜负的是底层物理量的改善斜率归谁，以及谁先补掉对手的短板（而不是谁攻击对手的短板）。

这篇的姊妹篇是 2026-07-13-gui-internet-cycle-vs-ai-analog.md——那篇讲真范式不构成估值安全边际（赢了技术≠赢了价格），这篇讲怎么判断谁会赢技术。两个问题必须分开问，混在一起是最常见的错。

一、案例档案：电动车 1900–1935 [KNOWN, HIGH]

起点：汽油是三条路线里最不被看好的那条

1900 年美国产 4,192 辆车：

动力数量占比
蒸汽1,68140%
电动1,57538%
汽油93622%

关键读法不是"电车占 38%"，是"78% 的车不烧汽油"。 电车巅峰 1912 年，全美约 3 万余辆注册 [MED，各来源 3.0–3.4 万浮动]；1920s 崩溃，1935 年前后基本消失。

死因拆解（按杀伤力排序）

#死因时点性质
①电启动马达（Kettering，凯迪拉克 1912 量产）1912补掉对手短板
②德州石油（Spindletop 1901）→ 汽油从炼煤油的废料变白菜价1901+投入品成本坍塌
③Model T 流水线：$850(1908) → ~$260(1925)，电车守在 ~$2,6501908–25定价战略自杀
④路网铺开 + 农村无电（REA 1935 前仅约 10% 农场通电）1916+互补资产缺位
⑤铅酸电池 1859 年发明，到 1920 年仍约 30–40 Wh/kg，几乎零改善；爱迪生镍铁电池又贵又晚全程底层物理量斜率为负
⑥Electric Vehicle Company（"铅酸出租车托拉斯"）1907 崩盘，污名化整个品类1899–07资本市场事故

最反直觉的一条

杀死电动车的是一个电动马达。

1912 年前汽油车要手摇曲柄启动——回火打断手腕是常事。电车的头号卖点从来不是环保，是"上车就走，不用摇"，广告直接打医生和女性市场。Kettering 的电启动机把这个优势一夜清零。

它没有让电车变差一分，它让油车不再烂。

二、抽出来的判据（框架主体）

⚠️ post-hoc 警告，先读这段：以下判据是从已知结局反推的，天然有拟合嫌疑。用户规则要求自问「不知道结局时，这个框架会不会做出同样预测？」——②③⑤⑥ 我认为会（它们在 1910 年代就是可观测量）；①④ 有事后聪明成分（当年没人预见 Kettering，也没人把"农村通电率"列为汽车指标）。第四节给了 out-of-sample 检验和失效边界，不看那节就用这个框架，等于自己给自己编故事。[INFERRED, post-hoc 已标注]

J1 · 底层物理量的斜率归谁 —— 最硬的一条

先问：这场路线之争，被哪一个可测量的物理量决定？ 然后看这个量在两条路线上的改善速度（不是当前水平）。

电车案例：能量密度。1859→1920 铅酸几乎不动，同期内燃机功率密度/可靠性/成本疯狂迭代。份额 38% 只是快照，斜率早就判了死刑。

用法：当前水平落后但斜率更陡 → 会赢；当前水平领先但斜率平 → 会输。永远看导数不看值。

J2 · 致命一击来自"补对手短板"，不是"攻对手长板"

行业里所有人都在盯"谁能在 X 上超过我"，而真正的杀手是"谁把自己在 Y 上的烂消灭掉"。

  • 电车盯的是"谁续航能超过我" → 死于对手不用摇车了
  • 找威胁的正确姿势：列出对手最大的用户痛点，问"如果这个痛点明天消失，我还剩什么？"

这是这个框架里最可操作的一条。

J3 · 当期份额是果不是因

38% 从来不是"领先"，是"三条路线还没分出胜负"。用份额判断路线胜负，是 1900 年和今天投资人共同的错误。

⚠️ 注意这条和 memory market-adoption-leading-signal（先看终端采用率，比财报领先）表面冲突，实则不同层：

  • 采用率是需求侧的领先信号 → 判断"这个东西有没有真需求"，有效
  • 路线份额是供给侧路线之争的滞后快照 → 判断"哪条技术路线赢"，无效

别把两者混用。

J4 · 互补资产的存在性（不是性能）

电车死于美国一半国土物理上没有电线——这不是"充电慢"，是"根本不能充"。

存在性问题（0 或 1）比性能问题（快或慢）致命一个量级。 评估新路线时，先列它依赖的外部基础设施，逐条问"这东西存在吗"，再问"够不够好"。

J5 · 主动放弃价格战 = 自杀

电车厂坚守豪华手工定位，眼看福特把价差拉到 5–10 倍。这是战略选择，不是技术必然。

用法：当在位者说"我们不做低端，我们做高价值"——这句话在路线之争里是投降信号，不是定位自信。

J6 · 资本市场事故会污名化整个品类

一个骗局（"铅酸托拉斯"）能让整个技术路线的融资窗口关上好几年。技术优劣和资本可得性是两条独立的死法。

三、框架自检：反向检验与失效边界

不做这一步，上面就只是一个漂亮故事。 [INFERRED]

检验 1：蒸汽车（同期第三方）—— 框架预测正确 ✅

蒸汽车 1900 年份额 40%，比电车还高，也死了。框架读数：J1 锅炉预热时间/水耗的物理约束改善缓慢；J2 汽油车的启动短板被补掉后蒸汽车"不用摇"的优势同样清零；J4 依赖沿途水源补给。三条判据独立指向死亡，与结局一致。

检验 2：交流电 vs 直流电（1880s–90s）—— 框架预测正确 ✅

J1 底层物理量 = 远距离输电损耗（∝ I²R，可用变压器升压压制）。交流在这个量上有结构性优势且不可被直流用工程手段追平。爱迪生当年的市场份额和先发优势完全不管用。J1 单条就定了结局。

检验 3：Betamax vs VHS —— 框架失效 ❌

底层物理量（画质）Betamax 更优，却输了。胜负由录制时长阈值 + 内容租赁生态 + 授权策略决定——这是网络效应之争，不是物理量之争。

失效边界（重要）：当胜负由网络效应/生态/标准锁定主导时，J1 反向失效——物理更优的一方可能输。 判断适用性的前置问题：「这个市场的转换成本主要来自物理限制，还是来自生态惯性？」 前者用 J1，后者用 J2+J5，J1 会给出错误答案。

这条边界对下面的 GPU vs ASIC 是决定性的——因为 CUDA 恰恰是生态锁定，不是物理优势。

四、套用到当前组合

4.1 GPU vs ASIC（NVDA 9.2% / MRVL 2.6%）[INFERRED, MED]

先判适用性：NVDA 的护城河 = CUDA 生态锁定 ≫ 硅片物理优势。→ 落在 Betamax 边界内，J1 不适用，主用 J2。

J2 提问：如果 ASIC 最大的短板明天消失，NVDA 还剩什么？

ASIC 的短板是不灵活——模型架构一变，专用硅就废。补掉这个短板的东西不是更好的 ASIC，是编译器/中间层抽象（XLA / MLIR / Triton 这一层）。

如果编译层成熟到"换硬件后端≈重编译"，CUDA 的转换成本 → 0，NVDA 的护城河不是被攻破，是被绕过。 这就是 NVDA 的电启动机时刻。

具体检验点：

  • 主流训练框架里非 CUDA 后端的生产级（不是 demo）占比
  • 大厂自研芯片承担训练（不只是推理）的比例——推理迁移易、训练迁移难，训练份额才是真信号
  • 与 memory ai-capex-cycle-topsignal-watchlist 里梁文锋"1 年内国产芯片生态被验证"（检验点 2027 年中）是同一个变量的中国侧版本——那条预言本质上就是在赌编译/生态层能把 CUDA 绕开

反面：模型架构仍在高速变化 → ASIC 的窗口一直被推后。这场仗的底层变量不是硅，是「模型架构的变更速率」。 架构冻结之日 = ASIC 赢面陡增之时。

4.2 HBM（内存腿 / MU、SKHY 论点）[INFERRED, MED-HIGH]

J2 提问：什么会杀死 HBM？

答案不是"另一种带宽更高的存储"，而是让带宽需求下降的东西：MoE / 稀疏与线性注意力（每 token 需要的带宽下降）、PIM（存内计算，把数据搬运本身消掉）、3D DRAM。

⚠️ 这不是新发现——tickers/MU.md 的「反向证据」表里早就列了这四条。框架在这里的价值是验证，不是创造，别把它当成新增信息。

J1 侧：内存墙（算力增速 > 带宽增速）这个物理差距仍在扩大 → 只要 Transformer 类架构不变，HBM 的底层斜率是向好的。HBM 的风险是架构风险，不是物理风险。

叠加长鑫（2026-07-27 IPO）：长鑫打的是常规 DRAM，不是 HBM——它冲击的不是护城河，是当下利润表最肥的那条腿。这属于供给侧竞争，不是路线替代，不适用本框架，走周期分析（见 2026-06-24-memory-storage-cycle-mechanics.md）。

4.3 光互连 vs 电互连（MRVL 2.6% / 光复合体）[INFERRED, MED-HIGH]

这是组合里 J1 最干净的一条。

底层物理量 = 每比特每距离的能耗。电互连的能耗随距离与速率恶化得比光快，光有一个 break-even 距离——而这个 break-even 距离随速率提升单调下降：机柜间 → 板间 → 片间（CPO）。

斜率是单调的、由物理决定的、且不依赖任何厂商执行。 这是本框架给出的最强"物理站在这边"判断。

但（必须说）：J1 判的是路线赢，不是某家公司赢。光路线赢 ≠ MRVL 赢——见姊妹篇「真范式不构成估值安全边际」。别把 J1 结论直接翻译成持仓理由。

4.4 EV vs 增程/插混 —— 直接的历史回响 [KNOWN/INFERRED, MED]

当年五条死因，四条已反转：

1900s 死因今天
电池 70 年零改善锂电 ~250–300 Wh/kg（铅酸 7–8×）；成本 ~$1,200/kWh(1991) → <$100/kWh（两个数量级）
农村无电（J4 存在性）电网基本全覆盖
价差 5–10×（J5）中国多个价格带电车已比油车便宜
续航 30–50 英里300+ 英里常态
汽油白菜价未反转

→ "历史重演、电车又不行了"在基本面上站不住。当年是电池物理打不过，今天电池物理已经赢了大半。

但 J2 的鬼魂在：纯电的短板是补能焦虑，补掉这个短板的是增程/插混——保留内燃机、消灭里程焦虑，结构上与 1912 年电启动机同型：用折中方案抹掉纯电的核心差异化，同时保住油车的便利。

检验点：中国增程+插混份额 vs 纯电份额的增速差（不是绝对份额，J3）。[当期数字需拉最新数据，我的知识截止 2026-01 之前]

七、这个框架的危险

触发我自己的 anti-sycophancy 红灯：它太优雅了，一个模式解释了太多东西。 具体风险：

  1. post-hoc 拟合：判据从已知结局反推（第二节顶部已标注哪几条最可疑）。
  2. J1 的"底层物理量"是我事后选的——选对了量框架就成立，选错了就是废话。同一个案例换个物理量能得出相反结论，这是框架最脆弱的关节。
  3. 失效边界真实存在（Betamax），而且当前 AI 算力之争恰好落在边界附近——CUDA 是生态锁定，不是物理优势。用错判据会得出完全相反的答案。
  4. 只做了 3 个 out-of-sample 检验，其中 1 个失败。样本量太小，33% 失败率不足以称为"框架"，更接近"一组值得问的问题"。

结论：把它当成 checklist 用，别当成预测器用。
