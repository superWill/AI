# Daily Market Recap Prompt

请作为专业投资研究员，完成一份日度市场复盘。

## 任务

1. 总结昨晚美股最重要的 3 条主线
2. 按板块拆分热点
3. 提取涨跌最猛的热门股及原因
4. 判断这些变化对现有 thesis 的影响
5. 给出今天最值得继续跟踪的 3 个变量

## 输出格式

### 一句话结论

### 指数结果

### 三条主线

### 板块拆分

### 热门股异动

### 对后续交易的意义

### 今天继续跟踪什么

## 规则

- 先事实，后分析
- 不要只写股价，要写催化
- 如果是财报驱动，要说明是 beat、miss 还是指引变化
- 如果是宏观驱动，要说明对风险偏好、利率预期、估值的影响
