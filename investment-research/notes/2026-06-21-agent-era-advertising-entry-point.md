# Agent 时代谁能做广告 / 谁是入口

> 起点问题：今天广告 = 社交(注意力) + 搜索(意图)。如果都用 Agent，谁是入口、谁还能收广告税？

## 一、广告的本质：对意图 + 注意力收税

- **搜索(Google) = 对意图收税**：你说出想要什么 → 拍卖答案位。~$2000 亿/年。
- **社交(Meta/抖音) = 对注意力收税**：你刷 → 插播打断。~$1500 亿/年。

## 二、三条结构性判断（高置信）

1. **Agent 先杀搜索，不杀注意力**。Agent 给一个答案 → 十条蓝链+四条广告的库存(搜索结果页)消失。娱乐刷流最抗打（人还是会无聊地刷）。
2. **广告供养的 Agent 自我毁灭（信任悖论）**。Agent 价值=替你干活；一旦被广告主收买，推荐被污染，干净对手赢走你。单答案 agent 没有"自然结果"可藏。
3. **变现从"广告"转向"抽成 + 订阅"**。Agent 帮你下单抽 GMV 一个点（agentic commerce）→ 长得像亚马逊/Booking，不像 Google 广告。**更准的问题是"谁对交易抽税"。**

## 三、入口 = 默认分发 × 信任 × 支付通道

| 玩家 | 角色 | 卡 |
|---|---|---|
| **Google** | 最该死(搜索广告被自家 agent 蚕食) + 武器最多(Android/Chrome 分发+Gemini+广告关系+支付) | [GOOGL](../tickers/GOOGL.md) |
| **Amazon** | 广告最抗 agent 化(零售媒体贴交易点) + agentic commerce 必经的交易通道 | [AMZN](../tickers/AMZN.md) |
| **Apple** | 黑马：拥有设备默认位+支付，**不靠广告→给得起"干净 agent"**；不造模型只对赢家收过路费。但 Siri 执行长期拉胯 | [AAPL](../tickers/AAPL.md) |
| **OpenAI** | 最直接的"搜索框继承人"，但信任悖论咬最狠 + 不在设备默认位 | 未上市 |
| **Meta** | **近期 AI 广告最强赢家**（已兑现：广告 +33%，曝光×单价双升，或 2026 超 Google）；但**长期 agent 入口最弱**（无"做事门口"）。capex 是悬顶 | [META](../tickers/META.md) |

## 四、二阶推论：品牌广告贬值，AEO 取代 SEO

Agent 替你选 → "建立认知好让你选"的品牌广告贬值（选的不是你）。营销从"说服人类"转向"挤进 agent 候选集 + 机器可读"（SEO → **AEO**）。**谁控制 agent 的候选集，谁对品牌有定价权**——这是 agent 时代真正的新收税口。

## 五、选股结论

- **GOOGL**：押"在位者成功转型"——bear(AI 杀搜索)正在被证伪(搜索 AI 化后仍 +19%)，但长期赌它用分发把 agent 入口锁在自己面上。
- **AMZN**：押"交易抽税赢过广告"——它的广告美元最抗 agent 化，且 Rufus/Buy-for-Me + 把 AI 购物技术开放给第三方零售商 = 想做 agentic commerce 的**基础设施**，无论商品留在 Amazon 还是走 agent，它都抽到税。

> 两者**与现有半导体书近乎不相关**（变现层 vs 铲子层），正好分散 [[portfolio-soxx-factor-risk]] 的 0.9x SOXX 集中度。
