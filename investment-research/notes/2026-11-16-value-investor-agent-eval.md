# value-investor agent 校验（2026-11-16）

> 起因：用户问「能不能训练一个巴菲特 agent 专门研究股票」。仓库里已经有 `.claude/agents/value-investor.md`，问题是没被用、没被检验过、不引原文。本篇记录当天做的三件事和一个结论。

## 一、结论（先说）

1. **回测 6/6 全对，但这个结果不能当证据。** 六个案例它全部认出或猜出了公司（它自己如实报告的），匿名化和缩放没挡住。它知道这些公司后来怎样。`[KNOWN，本次实测，HIGH]`
2. **回测能说明的只有两件小事：** 它不是一律拒绝（6 个里放行 2 个），也不是在同一关机械地停（停在第 1 关 1 次、第 2 关 3 次、四关全过 2 次）。`[COMPUTED，HIGH]`
3. **唯一干净的检验是前向记录。** 从今天起每份判决记一行，到复核日对照。见第四节。
4. **ANT：停在第 1 关，「不懂，过」。** 理由是讲不清十年后为什么还赚钱：单位经济没稳定、说不出客户不换的机制、领先按季度算。

## 三、六案例回测

**方法：** 六家公司在某个历史时点的状况，财务数字取自 SEC XBRL（10-K 年度值），整体乘一个固定系数，业务用不带名字的话描述。每个案例单独派一个 `value-investor`，要求只用材料、不上网、不猜公司，最后自报是否认出。用的是加语料规则**之前**的定义。

| 案例 | 真实公司 / 时点 | 巴菲特当时 | agent 判决 | 停在 | 之后的结果 | 自报是否认出 |
|---|---|---|---|---|---|---|
| A | IBM，2011 年底 | 买入 | 生意本身不行 | 第 2 关 | 差（巴菲特后来认错并清仓）| 是 |
| B | 苹果，2016-03 | 买入 | 生意可以价格也可以 | 全过 | 好 | 是 |
| C | 达美航空，2016-09 | 买入 | 生意本身不行 | 第 2 关 | 差（2020 年亏损清仓）| 有猜测（对）|
| D | 派拉蒙，2022-03 | 买入 | 生意本身不行 | 第 2 关 | 差（亏损清仓）| 有猜测（对）|
| E | 谷歌，2011-03 | 没买（后来称是失误）| 生意可以价格也可以 | 全过 | 好 | 是 |
| F | 英特尔，2021-03 | 没买 | 不懂，过 | 第 1 关 | 差 | 是 |

「之后的结果」和「巴菲特当时」两列是凭记忆填的 `[KNOWN，未逐条核实，MED]`。

**为什么 6/6 不算数：**

- 六个全被认出。它在 A 上还自己指出：定义里本来就点名「AVGO/IBM 型」是收购陷阱，这题等于提前给了答案。
- 六个案例是我挑的，挑的时候我也知道结果。三好三坏的配比是人为的。
- n=6。
- 判决和结果对上得太整齐，这本身就是该怀疑的信号。

**它给出的理由本身是站得住的**（不依赖后见之明也能从材料里读出来）：A 的回购加分红超过自由现金流、商誉超过股东权益；C 的利润率四年不动、Y0 的跳升来自燃油；D 的自由现金流只有净利润的 13%。但「理由站得住」和「当时就会这样判」是两回事，后者这次测不出来。

**一个副产品：** 它在 A、C、D 三笔上和巴菲特当时的实际操作相反。这说明这个 agent 不是在模仿巴菲特的买卖，而是在执行一套比他本人更保守的筛子。用的时候要清楚这一点。

## 四、前向记录（今后唯一算数的检验）

规则：每跑一次 `value-investor` 记一行；判决当天写明「什么情况说明它判错了」；到复核日回来填最后一列。满 10 行之前不对它的命中率下结论。

| 判决日 | 标的 | 判决 | 停在 | 什么情况说明它判错了 | 复核日 | 复核结果 |
|---|---|---|---|---|---|---|
| 2026-11-16 | ANT（Anthropic，未上市，区间 $70–78）| 不懂，过 | 第 1 关 | 首份 10-Q 披露了 Claude Code 或企业合同的留存 / 迁移数据，且算力成本占收入连续两季稳定在 50% 以下——即当时讲不清的单位经济其实是可以讲清的 | 首份 10-Q 后（约 2027-02，待核实）；2027-11-16 | — |

ANT 没有 `tickers/ANT.md`，判决暂记在这里；建档时搬过去。

**ANT 判决里它列的「不知道」：** 客户迁移成本的真实大小；Claude Code 单独的收入和粘性；经 AWS / Google Cloud / Azure 转售的收入占比；前沿领先能维持几年。

## 五、和前一天分析的关系

11/15 我用三档情景给出过 ANT 的门槛价（$60–65）和仓位上限。那是 `probability-analyst` 式的算法。`value-investor` 的结论是根本不该走到算价格那一步。两者并排摆着：

| | 情景 / IRR（11/15）| value-investor（11/16）|
|---|---|---|
| 结论 | $74 加权 IRR 约 +9%，$60–65 才够 | 不懂，过 |
| 分歧点 | 假设 2030 年收入和利润率可以给出区间 | 认为那个区间没有依据，因为单位经济和客户粘性讲不清 |

按 11/04 的规则（首份 10-Q 之后再评估），两种方法在动作上不冲突：现在都是不动。
