# BTC 周期底 = 杠杆大玩家爆掉 + MSTR 盯盘（2026-06）

## 一句话

**几乎每轮 BTC 大跌的底,都被一家过度杠杆的大玩家爆掉来标记(2014 Mt.Gox、2022 FTX/Terra)——因为暴跌本质是杠杆出清。这一轮的头号候选 = MSTR(反身 BTC 国库飞轮已反转:mNAV<1、$10.6B 浮亏、被迫卖币、优先股息覆盖只剩 14 个月)。盯 MSTR 是比盯价格更好的底部信号;它和 CRCL corr 0.58,爆雷会传染你的 CRCL。**

## 一、历史规律:每轮底的"那家公司" `[KNOWN]`

| 周期 | BTC 跌幅 | 爆掉的大玩家 |
|---|---|---|
| **2014** | -85% | **Mt. Gox**(~70% 交易量霸主交易所,丢 ~85 万 BTC,破产)——标志性崩塌 |
| **2018** | -84% | 较分散:**Bitconnect 庞氏崩 + ICO 泡沫归零**(无单一巨头,杠杆/骗局层集体内爆) |
| **2022** | -77% | **连环爆**:Terra/Luna(算法稳定币)→ 3AC(基金)→ Celsius/Voyager(借贷)→ **FTX(#2 所,$80亿欺诈)= 底** |

**机制**:牛市堆起杠杆玩家(用存款的交易所/借贷/高杠杆基金/庞氏)→ BTC 跌 → 被迫平仓 → 最大的爆掉 → 强平+传染砸出瀑布 → **底出现在"最大爆雷、杠杆冲干净"之后**。**爆雷既是症状也是加速器。**

## 二、这一轮候选:MSTR(反身飞轮已反转)`[KNOWN 2026-06]`

**实测**:MSTR **$94、市值 $34B、距顶 -79%、近 1 月 -41%**(2 年新低)。

> **⭐ 2026-06-28 更新(恶化在加速)** `[KNOWN 2026-06]`:MSTR **$82.31、市值 $28.8B**;**近 1 周 -26.9% / 月 -48.5% / 年 -78.7%**——失血提速,不是横烂。**mNAV:EV 0.99× / basic 0.58× / diluted 0.63×**(市值仅持币 $51.1B 的 ~0.56 倍,飞轮彻底断)。BTC ≈ $60.3K。**卖币 nuance 复杂化**:5/26-31 卖 32 枚付息后,**又买 1,550 枚 / $1.013 亿(~50x 卖量)**——说明还能融资买币、还没 FTX 式一夜爆,更像护"仍在买"叙事;但没解决 mNAV<1 + 卖币付息的结构病。**本周大量 put 买入触发抛售级联**。
- 原飞轮 = 股价对 BTC 溢价(mNAV>1)→ 发股/优先股 → 买更多 BTC → 循环。
- **现在 mNAV < 1**:市值 $34-36.5B **< 持有的 BTC 价值 $54.4B**(整个公司比它的币还便宜)→ **无法再增发买币(摊薄而非增厚)**。
- **但固定义务还在**:**~$15B 优先股、~$1.7B/年股息**;**现金年内 -38%、股息覆盖从 7 年→14 个月**;**$10.6B BTC 浮亏**(847,363 枚成本 ~$64.1B)。
- **2022 来首次卖币**(为付优先股息,破"永不卖"信条)→ 若 BTC 续跌,覆盖更差 → 更多卖币 → **死亡螺旋风险 + 砸 BTC 传染**。

**重要 nuance**:MSTR 债多为长久期可转债+优先股(非 3AC 那种短期 margin call),**不是 FTX 式一夜归零**;是**慢性失血 + 死亡螺旋风险**。但它是本轮最像"那家"的——**盯它 = 盯本轮底部信号**。

## 六、稳定币成功 → BTC 货币溢价被替代(2026-07-01 补)`[KNOWN 2026]`

> 用户问"稳定币成功是不是就不该持有 BTC?"——**推不出来,那是证据越界。稳定币改变的不是"要不要持有",是"为什么持有 + 持多少"。**

**结论:稳定币成功把 BTC 论点收窄,不是清零**:
- 死掉的是**"数字货币/支付"腿**(稳定币干得更好);活着但变窄的是**"非主权数字黄金"腿**——**它没死,但成了 BTC 唯一支柱,且 2025-26 压力测试里还没证明自己**。

**空头传导(有实证,占主导)**:
- **GENIUS Act(2025/7/18)= 政府背书数字美元** → 把"数字美元"需求从 BTC 分流到稳定币;**本质是"美元的成功",削弱"法币贬值→买 BTC"的核心多头逻辑**。
- **实测**:GENIUS 后 **BTC 2025/7→10 跌 43%,同期稳定币市值涨到 $3060 亿**;**黄金跑赢 BTC ~100%**;**BTC 没当避险,跟 SaaS/不盈利科技一起崩**(= 本 note §三"corr 0.96、杠杆风险非对冲"同现象)。Coindesk:GENIUS "repriced BTC 货币溢价"(往下)。
- 带息稳定币 = 加密圈内 **risk-off 停车位**,资本可从 BTC 逃入稳定币而不离场 → 竞争性资金分流。真受益者是 **ETH/SOL/L2(结算层),不是 BTC**。

**持有决策(不取决于稳定币,取决于三个自变量)**:
- **该清的人**:① 把 BTC 当对冲/分散腿(实证证伪)② 仓位大到亏不起(BTC 有真归零尾,不进核心)③ 为"支付叙事"持有(已被替代)。
- **可持小仓的人 = 用户**:明确赌"非主权储值 + 减半周期"、size 到归零不伤本金。**本就按"可归零彩票"sized,稳定币把论点变窄但没触发结构性退出**(用户从不为支付/对冲持有它)。

**对用户的具体判断**:**不该清,但别加、别放大、别改性质。**
1. 永远属"输得起"那桶,和退休核心物理隔离(归零尾,非看空)。
2. **别在这个点减**:BTC ~$60k、-51%、且本 note"周期底=杠杆爆(MSTR)"规律正在演——**杠杆洗盘中段砍小仓≈砍在接近底**。要减在情绪狂热期,不是恐慌期。
3. **预登记退出**(把变窄的论点变可证伪):**BTC 下次全市场 risk-off 仍不表现为 gold**(继续跟科技崩/被真黄金跑赢)→ "数字黄金"叙事证伪 = 真退出信号;或稳定币+CBDC 侵蚀"非主权储值"需求;或 size 涨到亏不起。

**一句话**:稳定币成功 ≠ 清 BTC,= BTC 持有理由只剩"数字黄金"一条、且未在压力下证明。动作是**保持小仓、别加、别当对冲、盯它下次危机像不像黄金**——别让一个正确的结构判断越界成恐慌期清仓。
