## 一、先定位：一条链，三段生意（这是关键，别混在一起比）

资深投研不会把这 8 家放一张表硬比——它们在**不同层**，对标要分段。

```
            AI 光互联价值链（从电信号 → 光 → 系统）
 ┌──────────────┬───────────────────┬────────────────────┐
 │  电侧芯片大脑  │     光器件/光源      │     光网络系统设备     │
 │  (DSP/SerDes) │  (激光/EML/硅光)    │   (相干传输/DCI/长途)  │
 ├──────────────┼───────────────────┼────────────────────┤
 │  AVGO  双寡头 │  LITE  激光最硬牌    │  NOK   系统三巨头      │
 │  MRVL  双寡头 │  COHR  宽器件平台    │  CIEN  北美传输龙头     │
 │  CRDO  互联PHY│  GLW   光纤/玻璃     │  (华为/Cisco)         │
 │  ALAB  Scale-up│                    │                     │
 └──────────────┴───────────────────┴────────────────────┘
        机柜内 / DC 内 ← 短链、走量 ─┼─ 长链、慢、运营商生意 → 机房间/城域/长途
```

- **MRVL / AVGO** 是电侧大脑——贴 GPU 集群，AI 弹性最直接。
- **LITE / COHR** 是光器件/光源——**全链最紧的瓶颈、定价权所在**。
- **NOK / CIEN** 是系统设备——机房间/长途，慢变量、运营商周期。

> MRVL 不和 NOK 竞争；MRVL 真正的对手是 **AVGO**，NOK 真正的对手是 **CIEN / 华为**。

## 六、资深 PM 的观察（落到能下单的结论）

1. **想押 MRVL 这波 AI 光逻辑，最便宜的入口其实是 COHR，不是 MRVL。**
   COHR 增速调整估值 0.31（全场最低），又直接持有"激光短缺"这张牌，距高点还 −12%。
   MRVL 的 0.79 看着贵，但 6/2 英伟达 $2B 是估值表里还没反映的增量——两者逻辑不同：
   COHR 买"便宜+瓶颈"，MRVL 买"全栈+英伟达催化"。

2. **MRVL 的真对手是 AVGO，不是 NOK。** AVGO Fwd PE 24.8 比 MRVL 35.9 便宜，体量 11×、
   更稳；MRVL 赢在纯度（数据中心占 75%）和增速弹性（Beta 2.25 vs 1.44）。
   → MRVL 是"高弹性进攻"，AVGO 是"确定性底仓"，可同时持、不同角色。

3. **NOK / CIEN 是另一个故事，别和 MRVL 混仓。** 系统设备是慢变量（NOK +7%）。
   CIEN 增速好（+24%）但 Fwd PE 125 已是 narrative 价。要系统暴露，NOK 更便宜但更慢，
   CIEN 更快但更贵——都不该当"AI 算力直接弹性"来买。

4. **最危险的位置：ALAB / CRDO。** 增速最猛但 P/S 40–55×、Beta >3，
   完美定价 + 高波动 = 任何 AI capex 杂音先砸这两个。

### 一句话配置框架

```
进攻弹性  : MRVL（全栈+英伟达）        ── 高 Beta 主攻
便宜瓶颈  : COHR（0.31，激光短缺）     ── 性价比首选
确定底仓  : AVGO（$2.2T，PE 24.8）     ── 压舱石
定价权纯   : LITE（唯一200G EML）       ── 但已 −17%，波动大
慢变量观望: NOK / CIEN                 ── 系统盘，非算力弹性
高危回避  : ALAB / CRDO                ── 完美定价，容错零
```

## 七、跟踪信号

- **份额迁移**：MRVL vs AVGO 在 1.6T DSP 的代际领先；NOK vs CIEN 季度份额。
