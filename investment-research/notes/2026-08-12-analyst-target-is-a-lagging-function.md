# 分析师目标价是价格的滞后函数，不是顶部信号

## 一句话

**净上调比例与「过去 3 个月收益」相关系数 +0.559，与「未来 3/6/12 个月收益」相关系数 +0.03 / −0.02 / −0.05。分析师在股票涨完之后上调；上调聚集在顶部附近，但因果是「价格 → 上调」，不是「上调 → 顶部」。**

**可操作推论：看到集中唱多，不代表要见顶，代表你已经错过了那段涨幅。**

---

## 一、起因：TSLA 2025-12 那次

流行说法是「投行 2025 年 12 月把 TSLA 目标价集中定在 550–850 并反复重申，然后就见顶了」。

**实测（yfinance upgrades_downgrades 原始记录）** `[COMPUTED, HIGH]`：

**TSLA 峰值 = 2025-12-16 收盘 $489.88；2026-08-11 收 $332.81，距顶 −32.1%，八个月未收复。**

2025 年 12 月全部 7 条目标价动作：

| 日期 | 机构 | 动作 | 目标价 |
|---|---|---|---:|
| 12/08 | Morgan Stanley | Raises（但评级**下调**至 Equal-Weight） | 410 → 425 |
| 12/09 | Piper Sandler | Maintains | 500 |
| 12/15 | Wedbush | Maintains | 600 |
| — | **← 12/16 见顶 $489.88** | | |
| 12/19 | Truist | **Raises** | 406 → 444 |
| 12/19 | Deutsche Bank | **Raises** | 470 → 500 |
| 12/23 | Canaccord Genuity | **Raises** | 482 → **551** |
| 12/30 | Baird | Maintains | 548 |

**两处对流行说法的更正：**

- ❌ **区间不是 550–850，是 425–600**，中位约 500。仅 Canaccord(551)/Baird(548) 在 550 附近，**无一家到 850**。
- ✅ **但时序观察成立且更精确**：7 条里 4 条在见顶之后，**三次真正的上调（Truist / DB / Canaccord）全部发生在 12/16 之后**。

## 二、普遍性检验

**样本**：TSLA / NVDA / AAPL / MSFT / GOOGL / META / AMZN / MU / AMD / AVGO / NFLX / INTC，2018-01 → 2026-08，**871 个「股票-月」观测**（仅计入当月 ≥3 条评级动作的月份）。

**净上调比例** = (Raises − Lowers) / 当月动作总数。

### ① 未来收益（中位数）

| 分组 | n | 未来 3 月 | 未来 6 月 | 未来 12 月 |
|---|---:|---:|---:|---:|
| ⬆ 上调最集中（前 20%） | 175 | 8.31% | **13.53%** | **29.97%** |
| 全样本中位 | 871 | 6.63% | 16.10% | 32.27% |
| ⬇ **下调最集中（后 20%）** | 186 | 5.62% | **19.01%** | **35.61%** |

**6 / 12 个月口径，下调集中的月份反而跑赢约 5.5pp。**

### ② ⭐ 决定性的一组：过去 vs 未来

| | 相关系数 |
|---|---:|
| 净上调比例 vs **过去 3 个月**收益 | **+0.559** |
| 净上调比例 vs **过去 6 个月**收益 | **+0.515** |
| 净上调比例 vs 未来 3 个月收益 | +0.030 |
| 净上调比例 vs 未来 6 个月收益 | −0.018 |
| 净上调比例 vs 未来 12 个月收益 | −0.049 |

> ## **和过去的相关性 0.56。和未来的相关性 0.00。**

### ③ 单调性（按过去 3 个月涨跌分五档）

| 过去 3 月表现 | 当月净上调比例 |
|---|---:|
| 跌最多 | **−0.481** |
| 跌 | +0.075 |
| 平 | +0.467 |
| 涨 | +0.633 |
| **涨最多** | **+0.752** |

**完美单调。涨得越多，上调越集中。**

## 三、结论的准确表述

| | |
|---|---|
| ❌ | 「分析师唱多 → 见顶」——暗示因果，而 corr(未来)=0.00 不支持 |
| ✅ | 「分析师目标价是价格的滞后函数，几乎不含未来信息」 |

**机制**：分析师在股票涨完之后上调 → 涨幅大的股票天然更接近局部顶部 → **上调因此聚集在顶部附近，但那是共变，不是因果。**

**可操作推论**：集中唱多是**对过去的确认**，不是**对未来的预告**。看到它，说明你错过的是已经发生的那段。

---

## 四、必须自己拆掉的三条 caveat

1. **样本是 12 只大盘科技股、2018–2026 全程大牛市**（12 个月中位收益 32%）——**这是时代不是技巧**，且幸存者偏差重（12 只全部存活，仅 INTC 明显掉队）。

2. **「下调集中月份跑赢」很可能不是"分析师是反指"，而是"2018–2026 每次暴跌都该买"。** 下调聚集在暴跌之后，而那个窗口在这段历史里几乎全是买点。**本检验无法分离这两个解释。**

3. **相关系数全部在 ±0.05 以内 = 几乎无预测力。** 严谨结论是「**无信息**」，不是「**反向指标**」——**据此做反向交易同样没有依据。**

## 五、与既有框架的连接

这与 memory `ai-capex-cycle-topsignal-watchlist` 里的**「反应函数 v3」是同一现象的两面**：

- v3 的观察：**AMD Q2 双 beat + 数据中心 +107% + 指引 2027 翻倍，盘后仍 −7.5%**，因为它进财报前已从 7/29 低点涨了 **20.7%**。
- 本篇的观察：**corr(过去) = 0.56 / corr(未来) = 0.00**。

**共同结论：分析师上调、卖方 beat、目标价集中——都是「已被定价」的确认信号，不是「将要发生」的预告。** 判断一个利好还有没有价值，先问它有没有被抢跑，而不是问它本身好不好。

同理适用于 `dip-buy-trigger-signals-not-daycount`：**价格类信号（跌了几天 / 涨了几天 / 分析师上调）都属于同一类「对过去的描述」，触发器必须是基本面信号。**
