# Device Display MVP

## Goal

第一版产品先解决：共控机能采集换热站设备信息，并在嵌入式平台本地显示。

## MVP Scope

包含：

- 添加设备。
- 设备列表。
- 切换当前监控设备。
- 按设备类型自动生成默认采集点表。
- 一次侧数据显示。
- 二次侧数据显示。
- 循环泵状态显示。
- 补水泵状态显示。
- 板式换热器状态显示。
- MQTT 连接状态显示。
- 告警列表显示。
- 数据更新时间显示。

不包含：

- 自动控制阀门。
- 自动控制水泵。
- 远程参数下发。
- OTA。
- 历史曲线。

## Minimum Data Points

### 一次侧

- 供水温度。
- 回水温度。
- 供水压力。
- 流量。
- 调节阀开度。

### 二次侧

- 供水温度。
- 回水温度。
- 供水压力。
- 回水压力。
- 流量。

### 设备

- 循环泵运行状态。
- 循环泵故障状态。
- 循环泵频率。
- 循环泵电流。
- 补水泵运行状态。
- 补水泵故障状态。
- 板式换热器状态。

### 通信

- MQTT 在线/离线。
- 信号质量。
- 最近上报时间。

## Embedded Implementation Idea

```text
1. 用户添加设备，配置设备编号、类型和采集地址。
2. 采集驱动按设备地址读取传感器和设备状态。
3. 点表模块按设备 ID 更新当前值。
4. 数据校验模块判断数据是否可信。
5. HMI 快照模块把点表转换成页面需要的数据。
6. 本地屏每 1 秒刷新一次当前设备。
7. MQTT 每 5 秒上报一次遥测。
```
