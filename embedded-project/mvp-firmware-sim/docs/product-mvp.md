# Product MVP

## MVP Name

热能共控机最小自治控制器。

## MVP Goal

在没有真实硬件的情况下，先验证共控机最小产品闭环：

1. 能启动。
2. 能自检。
3. 能进入运行。
4. 能根据温度调阀。
5. 能根据压差调泵。
6. 能低压补水。
7. 能遇到危险进入保护。
8. 能通过 MQTT 上报状态。
9. 能断网继续本地运行。

## MVP Boundary

包含：

- 状态机。
- 安全保护。
- 基础控制算法。
- mock 点表。
- mock 设备输出。
- mock MQTT。

不包含：

- 真实 IO 驱动。
- 真实本地屏 UI。
- 真实 MQTT Broker。
- 真实 OTA 下载。
- 真实板卡适配。

## Success Criteria

- 正常场景下，系统从上电进入运行。
- 低压场景下，系统启动补水。
- 超温场景下，系统进入急停并关闭一次侧阀门。
- MQTT 离线场景下，系统继续本地运行。
- 关键传感器故障场景下，系统拒绝自动控制并进入保护。
