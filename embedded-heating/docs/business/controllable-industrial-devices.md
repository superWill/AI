# Thermal Energy Controllable Industrial Devices

本文梳理热能共控机在换热站和小区供热系统中常见可采集、可控制的工业设备，以及它们常用的协议、接口和典型数据。

## 2. Protocol and Interface Notes

| 协议/接口 | 适合对象 | 数据特点 | 工程注意事项 |
| --- | --- | --- | --- |
| DI 干接点 | 门磁、水流开关、压力开关、故障反馈 | `0/1` 状态 | 需要确认公共端、湿接点/干接点、常开/常闭逻辑 |
| DO 继电器/开关量输出 | 泵启停、阀门开关、报警输出 | `0/1` 指令 | 需要确认触点容量，必要时外接中间继电器 |
| 4-20mA AI | 压力、压差、液位、温度变送器 | 工程量连续值，抗干扰强 | 需要配置量程、断线判断，4mA 通常对应工程零点 |
| 0-10V AI | 电压型传感器、部分阀位反馈 | 工程量连续值 | 需要共地，长线抗干扰弱于电流环 |
| 4-20mA AO | 阀门开度、变频器频率给定 | 连续控制输出 | 需要确认执行器输入阻抗和量程方向 |
| 0-10V AO | 阀门/变频器模拟给定 | 连续控制输出 | 需要共地，注意最大输入电压 |
| RS485 Modbus RTU | 变频器、热量表、电表、远程 IO | 寄存器读写 | 需要确认地址、波特率、校验位、寄存器表、字节序 |
| Modbus TCP | 以太网 PLC、网关、变频器 | 寄存器读写 | 需要处理网络断线和重连 |
| M-Bus | 热量表、水表 | 表计读数 | 需要专用主站接口或网关 |
| CJ/T 188 | 国内水/热/气表 | 表计读数 | 需要确认表地址、数据项编码和校验 |
| DL/T 645 | 电表 | 电能和电参量 | 需要确认规约版本、表地址和倍率 |
| MQTT | 上位平台、云平台 | 遥测、告警、参数、命令 | 本地控制不能依赖 MQTT 在线，断网要自治 |
| HTTP/WebSocket | HMI、调试页面、平台接口 | 页面和实时推送 | 适合本地屏和调试，不直接承担硬实时控制 |

## 4. Mapping to Current BL412B Hardware

当前设备型号为 `BL412B-SOM412-X23-Y31-Y41`，可按以下方式落点：

| 硬件接口 | 适合接入 | 典型点位 |
| --- | --- | --- |
| X23 DI | 干接点和开关量输入 | 门磁、水流开关、压力开关、泵运行反馈、泵故障反馈、阀门到位反馈 |
| X23 DO | 开关量输出 | 泵启停、阀门开关、报警输出、中间继电器控制 |
| X23 RS485 | 总线设备 | 变频器、热量表、电表、远程 IO、Modbus 型压力/温度/流量仪表 |
| Y31 AI | 0/4-20mA 模拟量输入 | 压力传感器、压差传感器、液位计、温度变送器 |
| Y41 AO | 0/4-20mA 模拟量输出 | 阀门开度给定、变频器频率给定 |
| DAQ4212 AI | 电压型模拟输入 | 0-10V、0.5-4.5V、1-5V 传感器，多路采集实验 |

已验证的本机读取方式：

```bash
# X23 DI/DO
cat /sys/class/beilai/DI1/data

# Y31/Y41
/usr/sbin/ioy show
/usr/sbin/ioy get 1.1

# DAQ4212
cd /opt/energy-control/vendor/zishutech/python
LD_LIBRARY_PATH=/usr/local/lib/daqlib2:$LD_LIBRARY_PATH python3 daq4212_read_once.py
```

Y31 `ioy` 输出单位按通道模式理解。若模式为 `4t20`，`/usr/sbin/ioy get 1.1` 读到 `4.000000` 表示 `4mA`，通常对应 `0MPa` 表压或工程量下限。

## 5. Data Normalization Rules

不同协议和硬件接口最终应归一到统一点位模型：

```text
raw_value      原始值，例如 12.35mA、32768、1
engineering_value  工程值，例如 0.835MPa、42.5degC、35Hz
unit           单位
quality        good / suspect / fault / offline
timestamp      采样时间
source         DI / DO / AI / AO / Modbus / MQTT / Internal
```

建议最小字段：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `point_id` | `sec_supply_pressure` | 统一点位 ID |
| `name` | 二次侧供水压力 | 中文显示名 |
| `source` | `Y31.1` | 硬件或协议来源 |
| `raw_value` | `4.000` | 原始读数 |
| `raw_unit` | `mA` | 原始单位 |
| `value` | `0.000` | 工程量 |
| `unit` | `MPa` | 工程单位 |
| `quality` | `good` | 数据质量 |
| `updated_at` | `2026-05-19T08:00:00+08:00` | 更新时间 |

## 6. Implementation Priority

第一阶段优先接入：

1. X23 DI：门磁、水流开关、压力开关、泵故障反馈。
2. Y31 AI：二次侧供水压力、二次侧回水压力、补水压力。
3. X23 RS485：变频器、热量表、电表。
4. Y41 AO 或 RS485：循环泵频率给定、一次侧调节阀开度给定。
5. MQTT：实时点位、报警、参数、远程命令。

控制开发顺序建议：

1. 只采集和显示，不输出控制。
2. 增加数据质量判断和告警。
3. 增加手动控制输出，带权限和安全联锁。
4. 增加自动控制算法。
5. 增加断网自治、历史缓存和远程参数。
