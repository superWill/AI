# Device Templates

这个 MVP 按设备类型自动生成默认采集点表。真实项目里，这些模板后续可以变成配置文件，由平台或本地屏下发。

## Supported Device Types

- 换热机组
- 板式换热器
- 循环泵
- 补水泵
- 电动调节阀
- 温度传感器
- 压力传感器
- 流量计
- 热表
- 电表
- 变频器
- 通信网关

## Template Logic

添加设备时，用户只需要填写：

- 设备名称
- 设备编号
- 设备类型
- 采集地址

系统根据设备类型自动生成点位，例如：

### 换热机组

- 一次侧供水温度
- 一次侧回水温度
- 一次侧供水压力
- 一次侧流量
- 一次侧阀门开度
- 二次侧供水温度
- 二次侧回水温度
- 二次侧供水压力
- 二次侧回水压力
- 二次侧流量
- 循环泵频率
- 循环泵电流

### 循环泵

- 运行状态
- 故障状态
- 运行频率
- 运行电流
- 二次侧供水压力
- 二次侧回水压力

### 热表

- 供水温度
- 回水温度
- 流量
- 瞬时热功率
- 累计热量

### 通信网关

- MQTT 状态
- 信号质量
- 接入设备数
- 最近上报时间

## Real Embedded Mapping

真实嵌入式实现时，每个点位还需要补充：

- 数据来源：AI、DI、RS485、Modbus TCP、CAN、MQTT、本地计算。
- 寄存器地址或通道号。
- 数据类型：bool、int16、uint16、float、enum。
- 缩放系数。
- 单位。
- 量程。
- 质量判断规则。
- 采样周期。
- 是否上报 MQTT。
- 是否在 HMI 显示。
