## 1. 统一 IO 类型速查

| IO 类型 | 人话解释 | 常见电气量程 / 接口 | 典型用途 | 注意事项 |
|---|---|---|---|---|
| AI | 模拟量输入，把电压/电流读成数字 | `0-10V`、`±10V`、`4-20mA`、`0-20mA`、PT100/热电偶专用模块 | 温度、压力、液位、阀位反馈、流量反馈 | 4-20mA 可判断断线；0-10V 易受线阻和干扰影响，适合短线或柜内 |
| AO | 模拟量输出，把控制量变成电压/电流 | `0-10V`、`±10V`、`4-20mA`、`0-20mA` | 阀门开度指令、变频器频率给定 | 高风险输出要有限幅、手自动切换和安全态 |
| DI | 数字量输入，只看开/关 | 干接点、`24V DI`、`3.3V/5V TTL` | 泵运行反馈、故障反馈、急停、限位、压力开关 | 工业现场优先 24V/隔离输入，不要把 24V 直接接 MCU |
| DO | 数字量输出，只控制开/关 | 继电器输出、晶体管输出、开集/开漏输出 | 泵启停、阀门开关、声光、联动输出 | 继电器适合通断，晶体管适合频繁动作；感性负载要续流/浪涌保护 |
| Bus | 总线设备 | RS485 Modbus RTU、M-Bus、CAN、Ethernet Modbus TCP、厂家 SDK | 变频器、热量表、电表、采集模块、消防回路设备 | 总线点位要有地址、寄存器、数据类型、倍率、质量码 |
| Internal | 系统内部量 | 软件计算或状态 | 网络状态、告警等级、模式、质量码 | 不直接占硬件 IO，但要在 HMI/MQTT 显示 |

## 2. 热源 / 换热站设备清单

### 2.1 温度、压力、流量与环境

| 设备 / 测点 | 常见输入输出 | 典型量程 | 点表建议 | 用途 | 展示字段 |
|---|---|---|---|---|---|
| 一次侧供水温度传感器 | AI：`4-20mA` / `0-10V` / PT100 模块 / Modbus | `0-150℃` 常见；高温场景可到 `0-200℃` | `pri_supply_temp` | 判断热源能力、超温保护 | 当前值、单位、质量码、趋势 |
| 一次侧回水温度传感器 | AI / Modbus | `0-150℃` | `pri_return_temp` | 判断换热效果 | 当前值、趋势 |
| 二次侧供水温度传感器 | AI / Modbus | `0-100℃` 或 `0-120℃` | `sec_supply_temp` | 供温闭环控制核心输入 | 当前值、目标值、偏差、趋势 |
| 二次侧回水温度传感器 | AI / Modbus | `0-100℃` 或 `0-120℃` | `sec_return_temp` | 回温优化、换热分析 | 当前值、趋势 |
| 一次侧供水压力变送器 | AI：`4-20mA` / `0-10V` | `0-1.6MPa`、`0-2.5MPa` 常见 | `pri_supply_pressure` | 一次侧安全监测 | 当前值、上限、告警 |
| 二次侧供水压力变送器 | AI | `0-1.0MPa`、`0-1.6MPa` 常见 | `sec_supply_pressure` | 压差控制、高压保护 | 当前值、上限、告警 |
| 二次侧回水压力变送器 | AI | `0-1.0MPa`、`0-1.6MPa` 常见 | `sec_return_pressure` | 压差/低压保护 | 当前值、低限、告警 |
| 压差变送器 | AI：`4-20mA` | `0-100kPa`、`0-250kPa`、`0-600kPa` | `sec_delta_pressure` | 循环泵变频压差控制 | 当前压差、目标压差 |
| 流量计 / 热量表 | Bus：RS485 Modbus / M-Bus；或 AI/脉冲 | 按管径和表计，单位常为 `m3/h`、`GJ`、`kWh` | `pri_flow`、`sec_flow`、`heat_meter_energy` | 热量、流量、换热能力分析 | 瞬时流量、累计热量、通讯状态 |
| 室外温度传感器 | AI / Modbus / MQTT 平台下发 | `-40~60℃` 常见 | `outdoor_temp` | 气候补偿曲线输入 | 当前值、来源、更新时间 |

### 2.2 阀门、泵、变频器与补水

| 设备 / 测点 | 常见输入输出 | 典型量程 | 点表建议 | 用途 | 注意事项 |
|---|---|---|---|---|---|
| 一次侧调节阀执行器指令 | AO：`0-10V` / `4-20mA`；或 Modbus | `0-100%` 开度 | `pri_valve_cmd` | 控制进入板换热量 | 高安全场景优先失电关闭阀；软件输出要限幅和速率限制 |

| 循环泵启停指令 | DO：继电器 / 变频器 DI / Modbus | bool | `circ_pump_run_cmd` | 控制循环泵启停 | 关键泵建议保留手自动和硬接线联锁 |

| 循环泵故障反馈 | DI / Modbus | bool | `circ_pump_fault` | 泵故障保护 | 故障信号应参与联锁 |
| 循环泵频率指令 | AO：`0-10V` / `4-20mA`；或 Modbus | `0-50Hz` 或 `0-60Hz` | `circ_pump_freq_cmd` | 压差控制输出 | 优先 Modbus 可获得更多状态；AO 方案要确认比例和上下限 |
| 循环泵频率反馈 | AI / Modbus | `0-50Hz` 或 `0-60Hz` | `circ_pump_freq_fb` | 判断变频器执行情况 | 指令/反馈偏差报警 |
| 补水压力 | AI | `0-1.0MPa`、`0-1.6MPa` | `refill_pressure` | 补水控制输入 | 低压和补水失败要联锁 |
| 补水泵启停 | DO / Modbus | bool | `refill_pump_run_cmd` | 定压补水 | 补水不能无限运行，要有超时保护 |
| 补水泵故障 | DI / Modbus | bool | `refill_pump_fault` | 补水故障保护 | 故障后禁止继续自动补水 |
| 水箱液位 / 缺水开关 | AI / DI | 液位 `0-5m` 或 bool | `tank_level`、`low_water_switch` | 防空转、防缺水 | 缺水保护优先级高于自动控制 |

## 3. 消防 / 火灾报警与联动设备清单

消防点位和热源点位最大的差异是：多数消防设备不是普通 `0-10V/4-20mA` 模拟量，而是**地址回路设备、开关量模块、联动输出和状态反馈**。展示时应突出：地址、回路、状态、告警/故障、屏蔽、联动关系。

### 3.1 探测与报警输入

| 设备 / 测点 | 常见输入输出 | 典型量程 / 状态 | 点表/设备类型建议 | 用途 | 展示字段 |
|---|---|---|---|---|---|
| 光电感烟探测器 | 地址回路 / 二总线 | 状态：正常、火警、故障、屏蔽；部分设备上报烟雾模拟值 | `SMOKE_PHOTO` | 火灾探测 | 回路、地址、区域、状态、模拟值、阈值 |
| 离子感烟探测器 | 地址回路 | 同上；新项目少用，偏维保 | `SMOKE_ION` | 存量维保 | 同上 |
| 定温探测器 | 地址回路 | 报警阈值常见 `57℃`、`70℃`、`85℃` 等，按型号 | `HEAT_FIX` | 温升/高温报警 | 状态、温度值/阈值 |
| 差温探测器 | 地址回路 | 关注温升速率，阈值按型号 | `HEAT_DIFF` | 温升异常报警 | 状态、温升趋势 |
| 差定温组合探测器 | 地址回路 | 定温 + 差温 | `HEAT_COMBO` | 综合火灾探测 | 状态、温度/阈值 |
| 红外/紫外火焰探测器 | 地址回路 / DI / 继电器 | 状态：火警、故障；部分有灵敏度级别 | `FLAME_IR` | 明火探测 | 状态、灵敏度、故障 |
| CO 气体探测器 | 地址回路 / AI / Modbus | `ppm`，量程按型号，常见 `0-300ppm` 或更高 | `GAS_CO` | CO 报警 | 当前 ppm、报警阈值 |
| 可燃气体探测器 | 地址回路 / AI / Modbus | `%LEL`，常见 `0-100%LEL` | `GAS_FLAM` | 可燃气报警 | 当前 %LEL、阈值 |
| 手动报警按钮 | 地址回路 / DI | bool：按下/恢复/故障 | `MANUAL_CALL` | 人工火警触发 | 回路、地址、状态 |
| 消火栓按钮 | 地址回路 / DI | bool：按下/恢复/故障 | `HYDRANT_BTN` | 消火栓启泵请求 | 状态、所属区域 |

### 3.2 现场输入模块

| 设备 / 测点 | 常见输入输出 | 典型量程 / 状态 | 点表/设备类型建议 | 用途 | 注意事项 |
|---|---|---|---|---|---|
| 输入模块 | 地址回路 + 干接点 / `24V DI` | bool | `MODULE_INPUT` | 接水流指示器、信号阀、压力开关、设备反馈 | 要区分报警输入、监管输入、反馈输入 |

| 压力开关 | DI，经输入模块接入 | bool：动作/恢复 | `MODULE_INPUT` | 喷淋压力动作、泵启动确认 | 应和水流、泵状态联动展示 |

### 3.3 联动输出与声光广播

| 设备 / 测点 | 常见输入输出 | 典型量程 / 状态 | 点表/设备类型建议 | 用途 | 注意事项 |
|---|---|---|---|---|---|

| 声光警报器 | 地址回路 / DO | 启停状态 | `SOUNDER` | 现场声光报警 | 需考虑分区启动 |
| 消防广播终端 | 地址回路 / 广播总线 | 启停/分区 | `BROADCAST` | 应急广播 | 展示分区和播放状态 |
| 消防电话分机 | 电话总线 / 地址回路 | 摘机/呼叫/故障 | `PHONE` | 消防通信 | 展示通话/故障状态 |

| 排烟风机/正压风机输出 | DO / 控制模块 | bool | `MODULE_OUTPUT` | 排烟送风联动 | 需有到位/运行反馈 |

| 电梯迫降输出 | DO / 控制模块 | bool | `MODULE_OUTPUT` | 电梯消防联动 | 必须有迫降反馈 |

## 4. 常见 DAQ / 远程 IO / 采集控制模块

### 4.1 当前项目相关：ZishuTech DAQ-4210/4211/4212 系列

| 项目 | 典型规格 |
|---|---|
| 接口 | USB 2.0 + 100M Ethernet |
| 供电 | USB 总线供电，或外部 `12V/24V` |
| AI | 8 路单端模拟量输入 |
| AI 分辨率 | 16 bit |
| AI 量程 | `±5V` / `±10V` |
| AI 采样 | 公开资料描述最高 `200KSa/s`，所有通道同步采样；实际 DAQ-4212 需以厂家 SDK/手册确认为准 |
| AO | 1 路模拟量输出 |
| AO 分辨率 / 量程 | 12 bit，`±10V` |
| DIO | 4 路可配置输入/输出 |
| DIO 电平 | 3.3V CMOS，兼容 TTL 输入；不要直接接 24V 工业信号 |
| 其他 | 正交编码计数器、PWM，和 DIO 共用引脚 |
| 项目判断 | 适合柜内 USB/以太网高速采集；若要接 24V DI、4-20mA 传感器，需要前端隔离/转换模块 |

### 4.2 常见模块类型速查

| 模块类型 | 常见接口 | 常见量程 / 通道 | 适合接什么 | 代表产品/形态 | 选型注意 |
|---|---|---|---|---|---|
| 多功能 USB/Ethernet DAQ | USB / Ethernet / SDK | AI `±10V`、AO `±10V`、DIO `3.3V/5V` | 实验台、柜内采集、高速波形、阀位反馈 | ZishuTech DAQ-4210/4211/4212、NI USB DAQ、Advantech USB DAQ | 工业 24V 信号通常不能直接接；要看 Linux ARM64 SDK |
| RS485 AI 模块 | RS485 Modbus RTU | 4/8/10/20 路 AI；`0-10V`、`±10V`、`0-20mA`、`4-20mA` | 温度变送器、压力变送器、液位、阀位反馈 | ICP DAS M-7017/M-7017Z、通用 4AI/8AI Modbus 模块 | 优先选隔离型；确认电压/电流模式是否跳线或软件配置 |
| RS485 AO 模块 | RS485 Modbus RTU | 2/4 路 AO；`0-10V`、`±10V`、`0-20mA`、`4-20mA` | 阀门开度给定、变频器频率给定 | Advantech ADAM-4024、通用 2AO/4AO 模块 | 高风险输出要有断线/失联安全态 |
| RS485 DI/DO 模块 | RS485 Modbus RTU | 8/16/32 路 DI/DO；DI 常见 24V；DO 继电器/晶体管 | 泵反馈、故障、阀门限位、启停输出 | ADAM/ICP DAS/国产 Modbus IO | 区分干接点、湿接点、源型/漏型输入 |
| Ethernet IO 模块 | Modbus TCP / MQTT / REST | AI/AO/DI/DO 混合 | 分布式 IO、远距离站房 | Advantech ADAM-6000、BLIIoT Ethernet IO | 网络中断时本地控制要有降级策略 |
| RTD 温度模块 | RS485 Modbus / 专用 ADC | PT100/PT1000，常见 `-200~850℃` 理论范围 | 管道温度、设备温度 | PT100 Modbus 模块、I-7015 类 | 线制 2/3/4 线要匹配，现场常用 3 线 |
| 热电偶模块 | RS485 Modbus / 专用 ADC | K/J/T/E/R/S/B/N 等，范围按热电偶类型 | 高温烟道、炉膛、特殊热源 | I-7018/M-7018 类 | 要有冷端补偿；抗干扰和接地很重要 |
| 电能/热量表网关 | RS485 / M-Bus / Ethernet | 电量、流量、热量、温度 | 热量表、电表、水表 | M-Bus 网关、Modbus 电表 | 注意倍率、单位、寄存器大小端 |
| USB 转 RS485 | USB | `/dev/ttyUSB*` | 工业机扩展 RS485 | CH340/FTDI/CP210x 工业转换器 | 现场长期运行优先工业隔离版本 |
