# IVG-G4H 摄像头模组接线与上电验证

> 对象：杭州杰峰 **IVG-G4H** 网络摄像机模组（主控 **GK7205V210**），配套"9 芯网络摄像机专用防水尾线"。  
> 用途：把这块裸模组安全上电、引出网口，接成一台可用的 IP 摄像机，再按软件方案接入网关。  
> 软件接入（ONVIF/RTSP/发现/健康检查）见 `xiongmai-ip-camera-integration-plan.md`，本文只管硬件接线与上电前验证。  
> 数据以模组规格书与实物丝印为准；下表参数摘自规格书（文档版本 20230913）。

---

## 1. 模组关键参数（决定怎么接）

| 项 | [COMPUTED][HIGH] 规格书值 | [INFERRED][HIGH] 接线含义 |
|---|---|---|
| 主控 | GK7205V210，双核 32 位 DSP，H.265AI | IP 摄像机（板载以太网），非串口/Modbus 设备 |
| 电源 | **DC12V / 2A，功耗 ≤3W** | 用 12V 供电；不是 5V，不要接 5V |
| 供电绝对范围 | **VCC 9.6 ~ 14.4 V** | 超出此范围有损坏风险，留够裕量 |
| 网络 | 1×RJ45，10/100M 自适应，**与电源接口合并** | 网口差分对 + 12V 都从 **J1** 出 |
| 协议 | RTSP/FTP/DHCP/NTP/UPnP，支持 ONVIF | 上线后走 ONVIF/RTSP 接入 |
| IR-CUT | 推荐 5V 标准电压 IR-CUT，线圈内阻 20Ω，通电 <200ms | 日夜切换滤光片，接 J5 |
| 板型 | 38mm×38mm | — |
| PoE | "支持扩展 POE 供电" | 需另配 PoE 分离模块；本文走非 PoE（独立 12V + 网口） |

## 2. 板上接口（丝印 → 功能）

[COMPUTED][HIGH] 规格书"接口说明"列明：

| 丝印 | 功能 | 脚数 | 备注 |
|---|---|---|---|
| **J1** | **电源 + 网络（合并）** | 8P | 上电与上网的主接口，见 §3 |
| J5 | IR-CUT 驱动 | 2P | 日夜滤光片切换 |
| J44 | 补光灯 / IO | 6P | 白光/红光/LED/GND/IRIN/预留 IO |
| J45 | 音频输入（MIC） | 2P | MICN / AC_IN |
| J49 | 音频输出（喇叭） | 2P | SPKN / SPKP，推荐 8Ω2W |

### J1 电源网络接口脚位（8P，权威）

| J1 脚 | 定义 | 功能 |
|---|---|---|
| 1 | ETH_LINK_ACT_LED | 网络灯 |

## 3. 配套尾线（9 芯防水线）与 J1 的对应

[COMPUTED][HIGH] 尾线端子：`2P-2.0 + 4P/6P/8P-1.25`；线色 → 功能：

| 尾线 | 功能 |
|---|---|
| 2.0 红 / 黑 | +12V / GND（独立电源接口，给不走合并口的板子） |
| 1.25 红 / 黑 | +12V / GND |
| 1.25 白蓝 / 蓝 | TX+ / TX− |
| 1.25 白绿 / 绿 | RX+ / RX− |
| 1.25 紫 | LED 指示灯 |

[INFERRED][HIGH] **按功能映射到 J1（接线目标）：**

| 尾线（1.25） | 功能 | → J1 脚 |
|---|---|---|
| 红 | +12V | **J1-8** |
| 黑 | GND | **J1-7** |
| 白蓝 | TX+ | J1-3（ETHTX+） |
| 蓝 | TX− | J1-4（ETHTX−） |
| 白绿 | RX+ | J1-5（ETHRX+） |
| 绿 | RX− | J1-6（ETHRX−） |
| 紫 | LED | J1-1 或 J1-2（网络灯） |

[INFERRED][HIGH] 尾线 7 根 1.25 线对 J1 8 脚 → 有一个网络灯脚空着，正常。  
[INFERRED][HIGH] 走 J1 合并口时，**只用 8P-1.25 一根就够**（网 + 电都在里面）；2P-2.0 红黑那路可不接。

## 4. 这根尾线能不能用：结论

[INFERRED][HIGH] **能用**——它就是为这类网络摄像机模组配的复合尾线，提供的信号（12V/GND + TX±/RX± + LED）与电压（12V）和 IVG-G4H 的 J1 需求完全对得上。  
[INFERRED][HIGH] **但有唯一高风险点**：尾线规格只给"颜色→功能"，**不保证插头内每根线的物理脚序与 J1 的 1→8 一致**。直接插之前必须按 §5 验证，否则 **12V 错位到网口/LED 脚会烧 SoC/PHY**。

## 5. 上电前验证步骤（必须，按顺序）

> 原则：**先验证、后上电**。任一步不确定就停下，别赌。

1. **确认电压**：再次核对模组要 DC12V（§1）。电源适配器输出必须 12V（9.6–14.4V 内）。  
2. **确认尾线插头规格**：量 J1 是 8P、间距 1.25mm；选尾线的 **8P-1.25** 那版插头。  
3. **核对脚序（关键）**：尾线**先不上电**，插上 J1，用万用表通断档逐脚确认：  
   - 尾线 **红(12V)** 通到 **J1-8**；  
   - 尾线 **黑(GND)** 通到 **J1-7**；  
   - 白蓝/蓝/白绿/绿 分别落 **J1-3/4/5/6**。  
   只要 12V 或 GND 不在 J1-8/J1-7，**停**——用挑针把 1.25 端子从胶壳退出来重排，或换匹配尾线。  
4. **查短路**：上电前量 J1-8(12V) 对 J1-7(GND) **不得短路**（万用表电阻档，不应接近 0Ω）。  
5. **空载试电压**：尾线 12V/GND 接电源、**先不插模组**，量尾线输出确为 ~12V、极性正确（红正黑负）。  
6. **上电**：确认 1–5 全过，再把尾线插进 J1 上电。正常应：网络灯有反应、模组不发烫不冒烟；若异常立即断电。

| 验证项 | 判据 | 不过怎么办 |
|---|---|---|
| 电压 | 适配器 12V，落在 9.6–14.4V | 换 12V 电源 |
| 插头 | 8P-1.25 对 J1 | 选对版本尾线 |
| 脚序 | 红→J1-8、黑→J1-7、网线对→3/4/5/6 | 退端子重排或换线 |
| 短路 | J1-8 对 J1-7 不短路 | 检查端子/胶壳 |
| 空载电压 | 尾线输出 ~12V，极性对 | 检查电源与 2.0/1.25 接法 |

## 6. 上电之后（接入）

[INFERRED][HIGH] 上电 + 网线通后，它就是台普通 IP 摄像机：  
- 尾线另一端（防水 RJ45）进交换机 / PoE 交换机（非 PoE 路径用独立 12V）。  
- 默认获取 IP：支持 DHCP；雄迈/XM 系常见默认 `192.168.1.x`，用厂商 DeviceManager/SADP 类工具扫描确认。  
- 之后走 **ONVIF + RTSP** 接入网关，细节见 `xiongmai-ip-camera-integration-plan.md`（发现/RTSP 探测/快照/健康检查；视频流不进点表与 MQTT 遥测主链路）。

## 7. 风险与边界

| 风险 | 说明 |
|---|---|
| [INFERRED][HIGH] 脚序错位烧板 | 12V 落到 TX/RX/LED 脚直接损坏，§5 第 3 步必做 |
| [INFERRED][HIGH] 电压错误 | 接 5V 不工作、接 >14.4V 或反极性损坏 |
| [INFERRED][MED] 把 PoE 48V 接进 12V | 本文走独立 12V；用 PoE 须经 PoE 分离模块降到 12V，48V 直灌烧板 |
| [INFERRED][MED] IR-CUT 电压 | 推荐 5V 标准 IR-CUT，通电 <200ms，别长时间通电 |

---

[INFERRED][HIGH] 一句话：**线是对的，电压/信号都对得上；插 J1 前务必按 §5 量一遍脚序，确认 12V 落 J1-8、GND 落 J1-7、无短路，再上电。**
