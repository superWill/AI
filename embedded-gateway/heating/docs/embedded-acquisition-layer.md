# 采集层:底层硬件接口(GPIO / ADC / I2C / SPI / PWM / 1-Wire)

> 你已经会"协议层"(Modbus 走串口读设备)。这一课往下一层:**芯片级直读**——
> 传感器/执行器直接挂在板子引脚上,不经过 Modbus 这种协议。这是嵌入式真正的"底"。
> 配套:[常识清单](embedded-common-sense.md) · [踩坑清单](embedded-pitfalls.md)

---

## 0. 先分清两层(你在哪)

```
协议层(你会了): 网关 ──串口/RS485──► [带 MCU 的设备] 讲 Modbus → 读寄存器
芯片层(这一课): 板子引脚 ──直接──► [传感器/芯片] 用 GPIO/ADC/I2C/SPI 直读
```
- 现成的**工业仪表/变送器**:多是 Modbus(协议层)。
- **裸传感器芯片**(温湿度芯片、ADC、按钮、继电器、LED):直接挂引脚(芯片层)。

---

## 1. 六种接口:是什么 / 用在哪 / Linux 怎么读 / 坑

### GPIO —— 开关量(最基础)
- **是什么**:一个引脚,高/低电平。输出=驱动(继电器/LED/使能);输入=读(按钮/限位/状态)。
- **Linux 怎么玩**(现代用 libgpiod,旧的 sysfs):
  ```bash
  gpiodetect; gpioinfo                       # 看有哪些 gpiochip / 线
  gpioset gpiochip0 17=1                      # 把某条线置高(驱动)
  gpioget gpiochip0 16                        # 读某条线(输入)
  # 旧法: echo 17 > /sys/class/gpio/export; echo out > .../gpio17/direction; echo 1 > .../value
  ```
- **坑**:① 输入要配**上拉/下拉**,不然电平悬空乱跳;② 驱动大电流(继电器/电机)**不能直接用 GPIO**,要经三极管/MOS/继电器模块,且**单独供电、共地**;③ 引脚号 ≠ 物理脚号,要查 pinmux/设备树。

### PWM —— 调光/调速/模拟输出
- **是什么**:方波占空比可调,用来调 LED 亮度、风扇/电机转速、舵机、近似模拟电压。
- **Linux**:`/sys/class/pwm/pwmchipN/` → export → 设 `period`(周期 ns)和 `duty_cycle`(占空 ns)→ `enable`。
- **坑**:周期/占空单位是 ns;频率太低会闪/抖;驱动功率器件同 GPIO(隔离+供电)。

### ADC —— 读模拟量(传感器大头)⭐
- **是什么**:把电压变成数字。**0-10V / 4-20mA / 电位器 / 热电偶 / PT100** 这类**模拟传感器**全靠它。
- **Linux**(IIO 子系统):
  ```bash
  ls /sys/bus/iio/devices/                    # iio:device0 ...
  cat /sys/bus/iio/devices/iio:device0/in_voltage3_raw     # 原始值(0~满量程)
  cat .../in_voltage_scale                     # 每 LSB 多少 mV
  # 真实电压 = raw × scale(mV);再按传感器换算成物理量
  ```
- **坑(最多)**:
  - ① **量程/分压**:板子 ADC 一般只吃 0~1.8V 或 0~3.3V;**0-10V/24V 信号要先分压**,4-20mA 要**采样电阻**(如 250Ω→1-5V)。直接怼会烧。
  - ② **标定/线性化**:`原始值≠物理值`。要两点标定(如 0℃/100℃ 对应的 raw)、热电偶/PT100 要查表或公式。
  - ③ **基准与噪声**:参考电压不准、地噪声大 → 读数飘;多次采样平均、好好接地。

### I2C —— 两线挂多个芯片
- **是什么**:SCL+SDA 两根线,挂多个设备(各有地址)。**温湿度芯片(SHT30/AHT20)、EEPROM、RTC、小屏、IO 扩展**常用。
- **Linux**:
  ```bash
  i2cdetect -y 1                               # 扫总线 1 上有哪些地址
  i2cget -y 1 0x44 0x00 w                      # 读设备 0x44 某寄存器
  # 复杂设备用 Python smbus2 按手册时序读
  ```
- **坑**:① SDA/SCL **要上拉电阻**;② 地址冲突(两片同地址要改地址或换总线);③ 速率(100k/400k);④ 不通先用逻辑分析仪看**有没有 ACK**。

### SPI —— 高速四线
- **是什么**:MOSI/MISO/SCLK/CS,点对点高速。**ADC 扩展、Flash、彩屏、射频模块**常用。
- **Linux**:`/dev/spidevX.Y`,用 ioctl(`SPI_IOC_MESSAGE`)或 Python `spidev` 收发。
- **坑**:① 对齐 **mode(CPOL/CPHA)**,错了全是乱码;② 每个从设备一根 **CS**;③ 速率别超芯片上限。

### 1-Wire —— 单线温度
- **是什么**:一根线(+地)挂温度传感器 **DS18B20**(最常见),省线。
- **Linux**:`/sys/bus/w1/devices/28-xxxx/temperature`,内核驱动直接给温度,几乎零代码。
- **坑**:要 4.7k 上拉;线长有限。

## 2. 选型速查:什么传感器走什么接口

| 传感器/执行器 | 接口 |
|---|---|
| 按钮、限位、干接点、继电器、LED、使能 | **GPIO** |
| 调光、调速、舵机 | **PWM** |
| 0-10V / 4-20mA / 电位器 / 热电偶 / PT100 | **ADC**(+分压/采样电阻/标定) |
| 数字温湿度芯片 SHT30、EEPROM、RTC、IO扩展 | **I2C** |
| 高速 ADC、Flash、彩屏、射频 | **SPI** |
| DS18B20 温度 | **1-Wire** |
| 工业仪表/变送器(电表/热表/流量计) | **Modbus**(协议层,你会了) |

## 3. 上手计划(板子回来后跑,从易到难)

1. **GPIO 输出**:点一个 LED / 拉一个继电器模块(`gpioset`),万用表量电平。
2. **GPIO 输入**:读一个按钮(`gpioget`),理解上拉/抖动。
3. **ADC 读电压**:接一个电位器到 SARADC 脚(板子 40Pin pin35/37,满量程 1.8V),`cat in_voltageN_raw` × scale → 电压;做两点标定。
4. **I2C 读温湿度**:挂一片 SHT30(0x44),`i2cdetect` 扫到 → 按手册读温湿度。
5. **把它接进面板**:这些读数也能像 Modbus 那样进 `panel_config` 上小屏——采集层和你已有的 HMI 打通。

> 配套脚本(本目录):`acq-examples/`(GPIO/ADC 示例,板子回来直接跑)。

## 4. 这一层的"常识"(老手的肌肉记忆)
- **直读传感器先看电平和量程**:别拿 0-10V 怼 1.8V 的 ADC、别拿 GPIO 直驱继电器线圈。
- **原始值不是物理值**:ADC/传感器都要**标定+换算**。
- **不通先量波形/查 ACK**,别改代码瞎试(和串口那层一个道理)。
- **强弱电分开、共地、上拉/下拉**——现场一半的"灵异问题"在这。
