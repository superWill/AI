# 行业语义网关定位

> 这是当前产品方向的判断基线：不要把目标定义成“所有行业都能接的万能网关”，而是定义成“多协议接入底座 + 行业设备语义模板 + 本地安全控制闭环”。

## 1. 市场判断

市场上已经存在很多多协议网关、SCADA、OPC Server、楼宇集成平台和工业 IoT 平台。

它们通常擅长：

- Modbus、BACnet、OPC UA、MQTT、CAN、厂家协议等协议接入。
- 数据采集、协议转换、边缘转发。
- HMI、报警、历史数据、云端对接。

但它们并不天然解决：

- 这个寄存器在热能系统里代表什么。
- 这个点能不能参与控制。
- 这个 DO 是否必须绑定反馈。
- 这个消防点是火警、故障、屏蔽还是联动反馈。
- 这个设备在 HMI 上应该怎么展示。
- 这个控制动作需要哪些联锁和人工复位。

所以，通用协议接入不是差异点，行业语义和安全闭环才是差异点。

## 2. 产品定位

推荐定位：

```text
多协议接入底座
  +
热能 / 消防 / 楼控行业设备模板
  +
点表 / 质量码 / 状态机 / 联锁模型
  +
本地 HMI + MQTT / 平台接入
```

不要说：

```text
我们什么行业都能接。
```

更准确的表达是：

```text
我们提供多协议接入底座，并针对热能、消防、楼控等场景提供行业设备模板和本地联动模型。
```

## 3. 四层架构

### 3.1 协议接入层

负责把数据读回来、把命令写出去。

示例：

- Modbus RTU / TCP。
- BACnet。
- OPC UA。
- MQTT。
- CAN。
- 厂家私有协议。
- DAQ SDK。

这一层关心：

- 怎么连。
- 怎么读。
- 怎么写。
- 是否超时。
- CRC 是否正确。
- 设备在线还是离线。

### 3.2 设备点表层

负责把原始数据翻译成统一点位。

示例：

```text
raw = 12000
mA = 12.000
供水压力 = 0.80MPa
quality = GOOD
```

这一层关心：

- 寄存器 / 通道。
- 数据类型。
- 量程。
- 单位。
- 换算公式。
- 质量码。
- 报警限。

### 3.3 业务设备层

负责把点位组合成现场对象。

示例：

- 补水泵。
- 循环泵。
- 调节阀。
- 热量表。
- 电表。
- 消防主机。
- 消防回路。
- 排烟风机。

例如补水泵不是一个点，而是一组点：

```text
启动命令
运行反馈
故障反馈
手自动状态
运行时间
最近故障
```

### 3.4 行业应用层

负责行业场景和控制闭环。

示例：

- 定压补水。
- 供热温度控制。
- 压差控制。
- 消防状态汇聚。
- 联动反馈可视化。
- 告警闭环。

客户真正关心的是这一层。

## 4. 热能系统优先模板

第一阶段优先落地热能系统。

建议模板：

- 热源站。
- 换热站。
- 一次侧。
- 二次侧。
- 循环泵。
- 补水泵。
- 调节阀。
- 热量表。
- 电表。
- 温度测点。
- 压力测点。
- 流量测点。
- 变频器。

每个模板都应包含：

- 必需点。
- 可选点。
- 量程建议。
- 报警建议。
- 控制建议。
- HMI 卡片。
- MQTT 字段。
- 调试清单。
- 安全联锁。

## 5. 消防系统边界

消防系统不能简单当成普通 RS485 设备。

优先方向：

- 状态汇聚。
- 告警展示。
- 事件上报。
- 设备在线状态。
- 联动反馈可视化。

消防模板：

- 消防主机。
- 消防回路。
- 烟感。
- 温感。
- 手报。
- 输入模块。
- 输出模块。
- 声光警报器。
- 消防泵。
- 排烟风机。
- 防火阀。
- 卷帘。

关键边界：

```text
消防主机是安全主体。
网关优先做监测、展示、上报和辅助联动。
不能轻易替代消防报警控制器。
```

## 6. 核心产品差异点

不是：

```text
支持 Modbus。
```

而是：

```text
知道这个 Modbus 设备在热能系统里代表什么。
知道这个点是否能参与控制。
知道这个 DO 必须有反馈。
知道这个消防点是火警、故障还是屏蔽。
知道 HMI 应该怎么展示它。
知道 MQTT 应该怎么上报它。
知道异常时应该进入什么安全态。
```

这叫行业语义。

## 7. 最小产品路线

```text
第一阶段：热能系统
  温度、压力、泵、阀、热量表、电表、变频器

第二阶段：消防状态汇聚
  消防主机、回路、探测器、输入输出模块、联动反馈

第三阶段：楼宇 / 能源扩展
  BACnet、空调、水泵、照明、电表、能耗
```

底层协议可以通用，但行业模板要分阶段做。

## 8. 记忆句

```text
协议网关解决“能不能读到”。
行业语义网关解决“读到后是什么意思”。
控制网关解决“能不能安全动作”。
产品网关解决“现场人员能不能看懂和用起来”。
```

本项目的长期方向：

```text
协议接入 + 点表模型 + 设备模板 + 业务状态机 + HMI/MQTT 表达
```
