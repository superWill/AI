# Three.js 楼层设备状态原型

> PROTOTYPE：用于判断楼层立体展示是否适合网关产品，不是生产代码。

## 要回答的问题

楼层堆叠方案是否能让用户快速看出“哪一层、哪个设备、处于什么状态”？

评审已选定原 A 方案“楼层堆叠”，建筑剖面和数字孪生变体及原型切换器已删除。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端中显示的本地地址。

## 可操作内容

- 拖动旋转、滚轮缩放；
- 点击楼层，将该层展开；
- 点击设备，进入带 URL 状态的独立设备详情页；
- 设备模型和“名称＋状态”标签均可点击，键盘 Enter/空格也可进入详情；
- 设备详情页支持返回楼层总览，刷新后仍保持当前设备；
- 点击“模拟报警”，观察自动定位和状态变化。

## 边界

- 所有数据只在内存中模拟；
- 没有接入真实设备接口；
- 使用原生 Node 静态服务器，不依赖 Vite 等构建工具；
- RK3506 当前没有浏览器且资源不足，本原型面向桌面浏览器或未来 RK3566/RK3568；
- 确认方案后，应删除未采用的变体并按生产约束重写。

## 评审结论

- 选中方案：楼层堆叠；
- 保留交互：旋转、缩放、楼层展开、设备详情、模拟报警；
- 放弃元素：建筑剖面、深色数字孪生和底部方案切换器；
- 当前仍是桌面浏览器原型，尚未按目标硬件约束重写。
