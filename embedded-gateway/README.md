# Embedded Gateway

嵌入式网关项目集合。共用一套"现场设备采集 + 本地屏/HMI + 上行通信 + 断网自治 + 安全优先"的网关架构，按行业拆成两个板块：

- **[heating/](./heating/)** — 热源板块：换热站 / 小区侧供热共控机（MQTT 上行，板式换热器）。
- **[fire-alarm/](./fire-alarm/)** — 消防板块：火灾报警控制器 + 联动控制器一体机（二总线，GB / CCCF 强制认证）。

## 怎么放文件

- **网关通用知识**（与具体行业无关的）直接放在本目录下，例如：通用网关架构、采集框架、本地 HMI 框架、断网自治模型、MCU/RTOS 选型、硬件平台（RK3506 / BL410 等）共性调研。
- **行业专属内容**放进对应板块目录：
  - 热源相关 → `heating/`
  - 消防相关 → `fire-alarm/`

## 共性设计原则

| 维度 | 约定 |
| --- | --- |
| 控制优先级 | 安全优先：安全保护层不可被远程指令、本地手动或自动算法绕过。 |
| 离线能力 | 失去上行链路时，采集 / 判定 / 控制必须本地独立完成。 |
| 本地交互 | 都需要本地屏 / HMI。 |
| 数据链路 | 现场设备采集 → 本地判定/显示 → 上行上报（热源 MQTT，消防 GB 16806 接口）。 |

## 板块差异速览

| 维度 | heating（热源） | fire-alarm（消防） |
| --- | --- | --- |
| 控制对象 | 换热站 + 小区侧供热 | 火灾自动报警 + 消防设备联动 |
| 现场总线 | 工业设备（多协议） | 二总线（私有协议） |
| 上行协议 | MQTT | GB 16806 接口（RS-232/485/Ethernet） |
| 强制认证 | 无 | CCCF（取得证书才能销售） |
| 远程升级 | 需要 | 受法规约束，谨慎 |
