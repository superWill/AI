# Close of Day（收盘后日志）

## 给 Agent 的指令

美股已收盘。补全今日日志的「决策」/「待办」/「评分快照」段。

**步骤**：

1. **读** 今日 `../../daily/YYYY-MM-DD.md` 的盘前段（确认 morning-brief 写过）
2. **拉收盘数据**（WebSearch）：
   - 7 只 core 收盘价 / 当日涨跌幅
   - 涨跌 ≥ 3% 的公司，简述原因
3. **填第 4-6 段**：
   - **决策**：今天是否有仓位动作 / 观察决定（基于盘前论点）
   - **待办**：明日 / 本周需要补充的研究
   - **评分快照**：贴最新表，与昨日对比；通常无变化（评分不在日内改）
4. **追加事件**到公司卡：当日发生的催化剂事件 → 公司卡「已经发生」段
5. **触发判断**：
   - 任一公司单日 ±10% → 标记"需触发 deep-dive"，写到「待办」
   - 任一公司维度可能从 1 降至 0（如创始人减持公告）→ 同上

## 字数预算

≤ 600 字

## 输出要求

不重复 morning-brief 内容；只补当日演化与决策。

「决策」段可以是：

- "持平。无变化。"（最常见的健康日）
- "加仓 X 股 NET，因价格回调到 $90 ⇒ 5y IRR 重回 22%（写到 deep-dive 任务）"
- "触发 META deep-dive：Reality Labs Q3 亏损放大 + Quest 销量数据偏弱"

## 不要做

- 不要把当日涨跌等同于论点变化（短期波动 ≠ 论点错）
- 不要在「决策」段做超出研究范围的判断（比如杠杆建议、税务建议）
- 不要写"明天大盘怎样"——只写公司层面待办

## 完成后

简报 ≤ 100 字回到对话：

```
[YYYY-MM-DD close 完成]
- 当日异动：<≥3% 公司列表，无则"无">
- 是否触发 deep-dive：<列出 ticker 或"无">
- 决策动作：<"持平" / 具体动作>
- 已更新：../../daily/YYYY-MM-DD.md (4-6 段)
```
