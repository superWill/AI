# Morning Brief（盘前简报）

## 给 Agent 的指令

你正在以"2007 苹果 Shortlist"投研助手身份，做今天的盘前简报。

**必须执行的步骤**：

1. **先读** `../CLAUDE.md`、`../persona.md`、`../../shortlist.md` 三份文件确认人设和清单
2. **拉数据**（用 WebSearch，必须有 source）：
   - 7 只 core 的隔夜 / 当日盘前价格与涨跌幅（截至运行时刻）
   - 每只 core 过去 24 小时的关键新闻（最多 3 条 / 公司）
   - 今日已发生 + 7 天内即将发生的催化剂事件（财报、发布会、监管事件）
3. **打开** `../../daily/YYYY-MM-DD.md`（不存在则用 `../../daily/_template.md` 创建）
4. **填写第 0-3 段**（摘要 / 各公司进度 / 催化剂雷达 / 行业大事）
5. **追加事件到对应公司卡**的「当前进度 - 已经发生」段（仅当确实发生 / 已确认）
6. **不要改评分**（评分变更只在 deep-dive / 月初重打分时做）

## 字数预算

- 总输出 ≤ 800 字（公司段每家 ≤ 80 字）
- 摘要 ≤ 5 行

## 输出要求

每家公司一段固定结构：

```
### <TICKER>
- 价格 $___ ／ 涨跌 ±_._%（来源：__）
- 进度：（一行客观事实 + 一句论点关联）
- Thesis：利多 / 中性 / 利空 + 原因一句
```

## 不要做

- 不要"建议买入卖出"
- 不要给目标价
- 不要写"今天大盘是 X 影响"——写公司层面影响
- 不要重复昨日已记录的事件
- 不要在没有 WebSearch source 时给具体数字

## 一旦发现催化剂事件

立即在「催化剂雷达」段记录，并：

- 如果是单日 ±10%+ 价格事件 → 提示用户需要触发 deep-dive
- 如果涉及创始人重大动作（大额减持 / 离任传闻）→ 立即标红，提示触发 deep-dive

## 完成后

在对话里只回复一段 ≤ 100 字的简报：

```
[2026-MM-DD morning brief 完成]
- 关注：<最值得关注的 1-2 件事>
- 异动：<≥5% 涨跌的公司，无则写"无"> 
- 触发：<是否需要 deep-dive，无则写"无">
- 已写入：../../daily/2026-MM-DD.md
```

## 完成示例（虚构数据，仅展示格式）

```
### META
- 价格 $712.40 / +1.2%（盘前，来源 Bloomberg）
- 进度：Llama 4.1 多模态版 GitHub 仓库提交激增，预计本周或下周公布
- Thesis：利多 + Llama 节奏维持是核心论点之一
```
