# NET · Cloudflare

## 一句话 Thesis

**Cloudflare 的 320+ 城市 Anycast 网络是全球唯一离用户毫秒级的"边缘计算 + 边缘存储 + 边缘推理"统一底座。当 AI agent 大量调用模型，"低延迟 + 数据不出区域"会比"绝对算力最大"更重要——Workers AI 是新范式。Prince 是 Lutke 同级的产品狂创始人。**

## 当前进度（iPhone 时刻 = Workers AI 成主流推理路径）

**已经发生**

- Workers AI 全球 GA，支持 Llama / Mistral / 小型模型
- AI Gateway 路由 / 缓存 / 计费第三方模型 API
- Agents SDK 2024 发布
- 与 Hugging Face / Mistral / Replicate 多家合作
- 收购 Vectara（向量数据库整合）

**正在发生（截至 2026-01）**

- R2 + Workers + Vectorize 形成"边缘 RAG 栈"
- 企业 AI 推理 token 计费产品 ramp
- AI Audit / Bot Management for AI（AI bot 管理）成新一类产品
- 上线 GPU on-demand for fine-tuning

**待补全（2026.02 后）**

- Workers AI 的 token 处理量（Cloudflare Radar 数据）
- 是否有"边缘推理 = 标准做法"的 turning point
- 与 OpenAI / Anthropic 是否谈成更深层集成
- 企业 ARR 增速
